# 웹사이트 검수 기록

2026-09-27. 로컬 HTTP 사이트와 Codex 인앱 브라우저에서 검사했다. 외부 공개·호스팅 가입·DNS·Google Play 콘솔·게임 서버 변경은 하지 않았다.

## 구현과 화면

- 회사 홈·스튜디오·게임 상세·고객지원·정책 허브·개인정보·약관·계정 삭제·확률의 9개 페이지와 별도404.
- 회사 홈은 독립된 Ludos 브랜드와 제작 철학, 게임 아트는 작품 카드와 상세 페이지에 집중했다.
- 320px·768px·1440px 브라우저 폭에서 9개 경로를 확인했다. 실제 DOM 폭과 scrollWidth를 비교했으며 페이지 전체 가로 넘침을 발견하지 않았다. 390px 화면도 별도로 육안 확인했다. 실제 모바일 기기 브라우저 검증으로 간주하지 않는다.
- 메뉴 열기/닫기·Escape 초점 복귀, 게임 캡처 확대·닫기·Escape와 원래 버튼 초점 복귀, FAQ 펼침, 정책 목차와 환불 조항 이동을 확인했다.
- 본문16px, 정책 표 내부 가로 스크롤, 모바일 목차 접기, 키보드 초점,44px 조작 영역, 모션 감소·인쇄 스타일을 적용했다. 보조기기 전반의 접근성 인증을 수행했다는 뜻은 아니다.
- 확인한 브라우저 오류·경고 로그0건. 외부 글꼴·분석·광고 코드·입력폼·브라우저 저장소 사용을 추가하지 않았다.

## 소스·응답 검사

- `scripts/check.mjs`: 10 HTML, 내부 링크·이미지 경로218개, 단일 h1·중복 ID·앵커·정책 본문·내부 검토 내용 비노출 확인.
- 공개 확률의 장비13행·마탑11행과 JSON을 대조했다. 일반·보장·마탑 확률 합계, 소스36개 SHA-256, 실제 게임 버전과 카탈로그 일치를 검사한다.
- 개인정보·약관·삭제·확률·지원 경로 HTTP200, 없는 경로404 및 보안 응답 헤더를 확인했다. 개발 서버에서도 배포용 CSP를 적용해 검사했다.
- 필수 확인키 누락, 미확정 문서, 미승인 확률의 공개 빌드를 차단함을 확인했다. 현재 `release/`는 생성하지 않았다.

## 발견 후 수정한 항목

1. 회사 첫 화면에 게임 분위기가 과해지는 구조를 회사 중심 구성으로 변경했다.
2. 건너뛰기 링크의 화면 위 잔상, 모바일 목차의 밀집 배치와 작은 닫기 조작 영역을 수정했다.
3. 내부 정책 링크의 미변환과 환불 조항 앵커 오류를 수정했다.
4. 공개 업무 전화·신고 정보 표시, 문서별 공개 승인·필수 키·버전·확률 표/지문 검사를 보강했다.
5. 대용량 임시 PNG와 사용하지 않는 아이콘을 정리하고 필요한 WebP만 배포물에 포함했다.
6. 현행과 다른 스킬·확률이 보이던 예전 갤러리 캡처를 최신 개발 화면으로 교체했다. 자세한 출처는 [ARTWORK](ARTWORK.md)에 기록한다.
7. 미리보기 실행 중 Windows가 빌드 소스를 점유해 수정이 실패하는 문제를 확인했다. 빌드를 짧은 별도 프로세스로 바꾸고 서버 실행 중 소스 저장·자동 재생성을 재검증했다.

최종 출력은22개 파일·881,373바이트(약861KiB)다. 실제 채택한 게임 이미지7개는772,706바이트이며 새 유료 이미지 생성은 실행하지 않았다.

소스와 자동 검사 결과가 기준이며 대표 화면은 [검수 이미지 폴더](../Docs/QA/Website20260927/)에 보관한다. 갤러리의 개발 화면은 실제 휴대폰 로그인 성공·실기기 성능 검증의 증거가 아니다.

## 공개 전 남은 범위

사업자 표시, 실제 처리업체·국외 이전·보유/백업 기간, 법정대리인 동의, 실제 계정 삭제, 지원 메일 수신, 최종 AAB와 공개 문서 일치, HTTPS 배포 주소는 아직 확인이 필요하다. 자동 검사 통과가 법률 검토나 Google 심사 승인을 대체하지 않는다. [제공 자료](../Docs/Publishing/REQUIRED_INPUTS.md)와 [법무 검토](../Docs/Publishing/LEGAL_REVIEW_KO.md)를 기준으로 이어간다.
