# 웹사이트 아트 선정 및 최적화

2026-09-27. Ludos Interactive 사이트에서 사용하는 프로젝트 자산과 재현 절차를 기록한다. 게임용 원본은 변경하지 않았다.

## 선정

현재 게임에서 채택한 타이틀 원화·로고와 최신 게임 구현을 직접 렌더한 화면을 사용한다. 가로 원화는 성과 용이 잘리지 않는 16:9 구도로, 모바일은 길과 성의 세로 흐름이 유지되는 3:4 구도로 잘랐다. 인물·건물·문구를 새로 그리거나 원본에 없는 UI를 합성하지 않았다.

| 파일 | 크기 | 용도 / 출처 |
| --- | --- | --- |
| `kingdom-hero-1536.webp` | 1536×864 | 데스크톱 히어로. `Assets/UGUI/Art/Lobby/Lobby_Background.png` |
| `kingdom-hero-1024.webp` | 1024×576 | 같은 구도의 작은 화면용 srcset |
| `kingdom-hero-mobile.webp` | 768×1024 | 모바일 히어로. 동일한 원본의 중앙 세로 구도 |
| `kingdom-logo.webp` | 768×539 | 투명 배경의 한국어 타이틀 로고. `Assets/UGUI/Art/Lobby/Lobby_Logo_KO.png` |
| `gameplay-battle.webp` | 1080×1920 | 현재 전투 화면. `Docs/QA/ShopRevision20260927/battle-current.png` |
| `gameplay-mage.webp` | 1080×1920 | 활성 8종 마탑 편성. `Docs/QA/ShopRevision20260927/mage-current.png` |
| `gameplay-equipment.webp` | 1080×1920 | 현재 장비 뽑기 안내. `Docs/QA/ShopRevision20260927/equipment-gacha-current.png` |

세 화면은 **Unity Editor PlayMode에서 캡처한 개발 중 게임 화면**이다. 버전 0.15.0, Unity 6000.3.21f1, 1080×1920 뷰포트에서 실제 전투·UI 프리팹을 실행했다. `FoundationPlayValidation.RunShopReview`의 격리된 로컬 QA 데이터를 사용했으며 로그인과 서버 거래는 수행하지 않았다. 실제 Android 기기에서 캡처한 화면으로 소개하지 않는다. 화면 속 재화·성장 상태는 검증용 데이터이며 실제 이용자의 기록이나 출시 성과가 아니다.

캡처 출처는 `Recordings/ShopRevision/EditorScenes`이다. 검수해 선택한 원본 PNG 세 장만 `Docs/QA/ShopRevision20260927`에 보존하여 버전 관리되는 원본에서 WebP를 다시 만들 수 있게 했다. 이전 9월 22일 마탑·장비 화면은 제거된 스킬과 옛 구성을 포함하므로 갤러리에서 교체했다. 이전 QA 원본은 역사적 검증 기록으로 유지한다. 사이트에서 참조하지 않는 게임 아이콘 WebP는 배포 목록과 생성 스크립트에서 제거했고 게임 원본 아이콘은 보존했다.

화면 설명은 전투 / 마탑 스킬 편성 / 장비 뽑기 안내로 구분한다. 출시 시 구성과 표현이 바뀔 수 있다. 수치·상품·확률의 근거는 스크린샷이 아니라 실제 카탈로그와 출시 시점의 검증 결과다.

## 크기와 검증

타이틀 원본 1536² PNG 약 2.65 MB를 데스크톱용 약 180 KB와 모바일용 약 133 KB WebP로 인코딩했다. 실제 바이트 수, SHA-256, crop 좌표와 압축 설정은 `content/asset-manifest.json`에 있다. 원본 시점·원근과 형태는 보존하고 화면 비율만 바꿨다. 웹용 smooth 원화·로고 축소에는 LANCZOS를 사용했으며 인게임 도트 스프라이트를 재작성하지 않았다.

로고의 투명도를 확인했다. 스크린샷은 원본 해상도 그대로 무손실 WebP로 저장하고 다시 디코딩한 픽셀을 원본과 비교한다. 게임 화면을 크롭하거나 UI·숫자·캐릭터를 지우지 않는다. 모든 원본의 해시가 처리 전후 같은지도 검사한다. 히어로의 성·용·경계 잘림은 데스크톱/모바일 결과 이미지에서 직접 확인했다.

재생성: 프로젝트 루트에서 `python Website/scripts/prepare_assets.py`. Pillow가 필요하다. 스크립트가 원본 존재 여부·해상도·원본 해시 불변·무손실 픽셀 일치를 검사하고 manifest를 함께 갱신한다. 기존 출력과 원본 및 설정으로 재현할 수 있다.

## 도구와 비용

현재 Comfy Cloud OAuth 연결과 실제 도구 카탈로그 41개를 읽기 요청으로 확인했다. API 목록 첫 출력에서 Windows 인코딩 오류가 발생했지만 ASCII JSON 출력으로 다시 확인했다. 인증정보와 응답 내 비공개 정보는 산출물에 포함하지 않았다.

이번 아트 작업은 기존 채택본 재사용과 실제 게임 캡처로 처리했다. **Comfy/내장 이미지 생성 실행 0회, 신규 생성 이미지 0개이며 추가 생성 과금은 발생시키지 않았다.** 계정 전체 사용량과 다른 작업의 과금은 이 기록의 범위가 아니다. 신규 생성 실행이 없으므로 새 프롬프트·생성 API/편집 그래프를 만들지 않았다. 기존 원화 공정과 출처 기록은 `AI/comfyui/lobby/revision5/README.md` 이하에 그대로 보존한다.

## 게시 전 확인

- 게임 로고와 타이틀 원화는 이 저장소에서 이미 사용 중인 자산이며, 외부 캐릭터 원본을 웹에서 단독 배포하지 않는다.
- 게임·외부 에셋의 상업적 사용 권리 확인은 출시 라이선스 점검에서 따로 다룬다. 이 최적화 기록 자체가 저작권 보증은 아니다.
- 웹에는 선택한 WebP만 포함한다. 작업 스크립트·manifest·내부 QA 기록은 공개 사이트의 사용자 동선에 넣지 않는다.
