# 웹사이트 아트 선정 및 최적화

2026-09-27. Ludos Interactive 사이트를 위한 기존 프로젝트 자산의 배포용 후보이다. 게임용 원본은 변경하지 않았다.

## 선정

새로운 게임 장면을 만들어 실제 플레이처럼 보이게 하는 대신 현재 게임의 채택된 타이틀 원화와 실기기 캡처를 사용했다. 가로 원화는 성과 용이 잘리지 않는 16:9 구도로, 모바일은 길과 성의 세로 흐름이 유지되는 3:4 구도로 잘랐다. 인물·건물·문구를 새로 그리거나 원본에 없는 UI를 합성하지 않았다.

스크린샷은 **개발 중 실제 플레이 화면**이라는 설명과 함께 사용한다. Development Build 표시를 지우지 않았으며, 이번 작업에서 추가되는 상점이 포함된 최신 화면이라고 소개해서는 안 된다. 새 출시 빌드 캡처를 확보하면 같은 슬롯에 교체할 수 있다. 수치·상품·확률 안내의 근거는 스크린샷이 아니라 출시 시점의 실제 카탈로그와 검증 결과다.

## 크기와 검증

타이틀 원본 1536² PNG 약 2.65 MB를 데스크톱용 약 180 KB와 모바일용 약 133 KB WebP로 인코딩했다. 실제 바이트 수, SHA-256, crop 좌표와 압축 설정은 `content/asset-manifest.json`에 있다. 원본 시점·원근과 형태는 보존하고 화면 비율만 바꿨다. 웹용 smooth 원화·로고 축소에는 LANCZOS를 사용했으며 인게임 도트 스프라이트를 재작성하지 않았다.

로고의 투명도를 확인했다. 아이콘과 스크린샷은 무손실 WebP로 저장하고 다시 디코딩한 픽셀을 원본과 비교했다. 모든 원본의 해시가 처리 전후 같은지도 확인했다. 히어로의 성·용·경계 잘림은 데스크톱/모바일 결과 이미지를 직접 보고 확인했다.

재생성: 프로젝트 루트에서 `python Website/scripts/prepare_assets.py`. Pillow가 필요하다. 스크립트와 manifest를 보존하면 같은 원본·설정으로 출력 과정을 재현할 수 있다.

## 도구와 비용

현재 Comfy Cloud OAuth 연결과 실제 도구 카탈로그 41개를 읽기 요청으로 확인했다. API 목록 첫 출력에서 Windows 인코딩 오류가 발생했지만 ASCII JSON 출력으로 다시 확인했다. 인증정보와 응답 내 비공개 정보는 산출물에 포함하지 않았다.

이번 아트 작업은 기존 채택본 재사용으로 품질·일관성·최적화 목표를 충족한다. **Comfy/내장 이미지 생성 실행 0회, 신규 생성 이미지 0개이며 추가 생성 과금은 발생시키지 않았다.** 계정 전체 사용량과 다른 작업의 과금은 이 기록의 범위가 아니다. 신규 생성 실행이 없으므로 새 프롬프트·생성 API/편집 그래프를 만들지 않았다. 기존 원화 공정과 출처 기록은 `AI/comfyui/lobby/revision5/README.md` 이하에 그대로 보존한다.

## 게시 전 확인

- 게임 로고와 타이틀 원화는 이 저장소에서 이미 사용 중인 자산이며, 외부 캐릭터 원본을 웹에서 단독 배포하지 않는다.
- 게임·외부 에셋의 상업적 사용 권리 확인은 출시 라이선스 점검에서 따로 다룬다. 이 최적화 기록 자체가 저작권 보증은 아니다.
- 웹에 선택한 파일만 복사한다. 작업 스크립트·manifest·내부 QA 기록은 공개 사이트의 사용자 동선에 넣지 않는다.
