# 재활용용 신 스킬 아트

신 스킬 시스템은 폐기되었습니다. 메뉴·뽑기·카드 데이터·실행 코드는 제거했고, 이 폴더의 이미지만 향후 다른 콘텐츠에 재사용할 수 있도록 보존했습니다.

- `Illustrations`: 기존 생성 일러스트·아이콘·컷인과 원본 메타.
- `VFX`: 기존 효과 시트·애니메이션·프리팹. 전투에서 자동 등록하거나 호출하지 않습니다.

아트 GUID는 보존했습니다. 공용 VFX 풀과 몬스터 상태이상은 `_Project/Scripts/Combat`으로 이동하여 현재 마탑에서 사용합니다. 이 폴더는 활성 UI 아틀라스에 포함하지 않습니다. 기존 실행 기록·프롬프트는 `AI/comfyui`에 보존되어 있으며, 옛 8종 디자인을 신규 콘텐츠의 확정안으로 사용하지 않습니다.
