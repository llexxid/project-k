# 마탑 개화 아이콘과 VFX 개선

기본 아이콘 10종을 참조로 ComfyUI에서 개화 변형을 제작했습니다. 천벌은 보라색 전기, 나머지는 작은 빛과 균열을 추가해 원본 형태를 유지합니다. `manifest.json`에 실제 제출 설정·프롬프트·작업 ID·출력 해시·Cloud 저장 ID를 연결했습니다. 각 폴더에 API JSON과 로컬/Cloud 편집 그래프를 보존했습니다. 정확한 배포 노드 버전은 API에서 노출하지 않았습니다.

Lightning 파일럿 확인 후 나머지 9종을 생성했습니다. 기존 참조의 형태 보존이 핵심이므로 다른 픽셀 LoRA를 섞어 재설계하는 대신 참조 편집, nearest 축소, 16색 마감을 사용했습니다. 모델/LoRA/노드 조회 결과를 함께 보관합니다. 프레임별 확산 생성은 하지 않았습니다.

VFX는 소유 작업본 시트의 정확한 팔레트 변경, 승인 아이콘의 실루엣 추출, Unity 애니메이션과 이동을 조합했습니다. `vfx-review-v1`은 첫 Android 검수 버전이며 `vfx-derivatives.json`은 현재 결과입니다. 원본 ExternalAssets는 변경하지 않았습니다.

완료 작업 10건의 표시 사용량은 171.80 Comfy 크레딧입니다. 이는 청구 달러가 아닙니다. 초기 두 사용량 보고서는 08:00 UTC 이전까지만 집계했으나, 검증 후 조회한 `usage-post-validation.json`은 작업 10건이 수행된 08:00–09:00 UTC 구간의 청구 기반 지출 **$0.8141358**를 반환했습니다. 시간/제품별 집계이므로 개별 작업별 영수증과는 구별합니다. 계정 월간 총액은 이번 작업 비용으로 사용하지 않았습니다.

최종 Android 검수에서 비전 탄환의 방향, 운석 낙하, 천벌의 폭과 명도, 바위 뒤로 보이는 적 실루엣을 확인했습니다. 전체 결과와 이전 시안은 프로젝트 검증 기록으로 연결합니다.
