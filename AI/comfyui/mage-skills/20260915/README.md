# 마탑 아이콘·뽑기 버튼·낙뢰 구름

[manifest.json](manifest.json)이 채택 출력, 실제 작업 ID, 원본 경로, 설정 및 비용의 연결표입니다. 행동 규칙은 저장소 AGENTS.md를 따릅니다.

## 공정과 선택

- 라이트닝: 내장 이미지 생성과 Gemini Flash Lite 시안을 비교했습니다. 작은 표시에서 번개의 굵은 실루엣이 더 잘 남는 내장 생성본을 채택했습니다.
- 나머지 9종: 채택 라이트닝을 스타일 참조로 ComfyUI의 Gemini Nano Banana 2를 사용했습니다. 얼음 송곳으로 참조 연결과 48px 출력을 먼저 검증한 뒤 독립 8종을 한 번의 batch로 제출했습니다.
- 마감: PixelOE의 nearest/k-centroid 대안 4회는 Cloud의 누락 모듈 때문에 실패했습니다. API·UI 그래프와 실패 응답을 보존했습니다. 지원되는 core nearest-exact 48×48 → 16색 양자화를 채택했습니다. 내장 생성 한 가지에만 의존하지 않았으며, 새 도구 호출 수보다 작은 화면의 일관성을 기준으로 선택했습니다.
- 뽑기: 내장 생성의 어두운 목재·청동 마스터 → Comfy crop/nearest 512×100/32색/알파 복원. 9-slice 스프라이트로 사용하고, 복사한 ElectricTornado 시트의 청색 가장자리 불꽃을 0.48초 재생합니다.
- 낙뢰 구름: 첫 기기 검수에서 전기 고리로만 보인 결손을 보완했습니다. 연속된 구름 실루엣 한 장을 생성한 뒤 Comfy에서 64×24, 최대 6색, 이진 알파로 마감했습니다. 실제 출력은 불투명 4색입니다. 기존 전기 애니메이션을 겹치며 프레임별 확산 생성은 하지 않았습니다.

## 보존 자료

`discovery/`는 당시 실제 모델·노드·템플릿 탐색 응답입니다. 각 버전의 `*.api.json`과 `*-request.json`은 실행 입력, `submission`/`status`/`output`은 실제 결과, Cloud 저장 응답과 `*.cloud.ui.json` 또는 `finish.ui.json`은 편집 가능한 서버 그래프입니다. 일부 `workflow.ui.json`은 실행 전 로컬 변환본이므로 Cloud에서 다시 받은 그래프와 구별합니다. 원본·미채택본을 삭제하지 않았습니다.

노드의 Cloud 설치 버전과 내장 이미지 생성 모델 버전은 응답에서 확인되지 않았습니다. Gemini seed는 제출했으나 재현성을 보장하지 않습니다. 내장 생성은 seed를 제공하지 않습니다.

## 비용

`billing-final.json`에서 작업 ID로 대응되는 실제 API 사용량은 **163.14 credits**입니다(Flash 9회×17.18 + Lite 시안 8.52). `usage-final.json`의 **$45.35084**는 8월 15일 18시–9월 15일 18시 UTC의 계정 전체 사용량이므로 이번 작업 합계가 아닙니다. GPU 마감·실패 비용의 작업별 금액과 내장 생성 비용은 확인되지 않았습니다. 마지막 구름 마감은 조회 시간창 이후 작업이므로 이 계정 합계에 포함됐다고 주장하지 않습니다.

최종 채택 검수는 [실기기 보고서](../../../../Docs/ArtPreparation/MAGE_INTEGRATION_VALIDATION.md)와 함께 확인합니다.
