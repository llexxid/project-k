## CombatRPG 키아트 참고

원본 경로:
`Assets/ExternalAssets/CombatRPG/2.08 - 550+ Animated + New Chatarcters/Epic Characters #31 - Animated/100 - Characters - 256x256 - Static`

측정 참조: `13.png`, `1.png`, `40.png`. 각각 스태프·마법진·갑옷의 재질 사례다.
CombatRPG 세트마다 윤곽선·알파·색 수가 달라 서로 같은 화풍으로 간주할 수 없다.

| 관찰 항목 | 당시 값 |
|---|---|
| 비율 | 성인 애니 6–7등신 |
| 고유색 | 256px 기준 약 5,800–17,700색 |
| 명암 | 재질당 5–10단계 램프 |
| 윤곽선 | 2.08 세트는 실루엣 1px 어두운 선 |

| 알파 | 불투명 영역의 94.7–98.5%가 250 이상 |

이 값은 고색상 카드 원본의 관찰값이며 신 캐릭터의 금속색·포즈·조명·팔레트를 강제하지 않는다.
당시 일부 원본은 Default/Bilinear/mipmap ON/NPOT 리샘플 설정이었다. 사용할 파일의 현재 import 설정을 확인한다.

## 인게임 도트 참고

| 실제 시트 | 당시 고유색 |
|---|---|
| Royal/Elite 직업 8종 | 14–29색 |
| Elite_Knight / Elite_Mage | 14 / 29색 |
| FireTornado / IceSpike | 5 / 2색 |

초상화는 실제 시트를 잘라 정수배 확대한다. 별도 확산 생성이나 HD 이미지를 시트 팔레트에 강제로 스냅하는 접근은 동일성을 해쳤다.
새 효과 아이콘은 논리 48px, 인게임 VFX는 논리 48–64px 프레임을 참고한다. 평면 색 덩어리와 실제 스프라이트의 도트 크기를 비교한다.
VFX 타이밍의 기존 참고값: 발동 50–60ms/frame → 유지 약 100ms → 소산 115–220ms. 실제 스킬 타이밍이 우선한다.

## 과거 공정의 출처

- 초기 카드: 원본 참조 스트립 → `GeminiNanoBanana2V2` → 로컬 마감.
- 이후 Astra/Ignis: 마스터 참조 편집과 캐릭터별 팔레트 공정. 각 폴더의 빌더·manifest·프롬프트 참조.
- `Assets/DivineSkill/Editor/GeneratedArtPostprocessor.cs`는 생성 아트 import 진입점이다. 현재 설정은 코드와 실제 importer에서 확인한다.

실제 실행 프롬프트·설정·원본·채택/기각본은 각 버전 폴더에 보존한다. 이 측정 요약은 과거 실행 기록을 대체하지 않는다.
