# Android 실기기 검증 — 2026-09-12

Galaxy Note20 Ultra **SM-N986N**, Android 13/API 33, Adreno 650, Vulkan, RAM 약 10.6GB. Unity **6000.3.21f1**의 ARM64 IL2CPP Development 빌드를 실제 USB 연결 기기에 설치했다.

원래 bootstrap → title 진입 경로와 배포 프리팹·컨트롤러를 사용했다. `.lobbyqa` 패키지로 기존 게임 데이터와 분리했으며 Google 계정 로그인이나 서버 계정 생성은 실행하지 않았다.

## 발견한 문제와 조치

1. **넓은 화면에서 시작 안내의 배경 대비 부족.** 밝은 길 위에 흰 안내가 올라오므로 기존 4×128 하단 페이드의 알파 곡선을 보강했다. 추가 이미지나 드로콜 없이 해결했고, 기기의 넓은 화면 캡처로 확인했다. 새 배포 이미지 합계는 **5,050,425바이트**다.
2. **앱 시작 시 Missing Script 경고.** 클래스 전체가 주석 처리된 구형 `WaveManager` 참조가 bootstrap의 GameManager에 남아 있었다. 해당 참조 하나와 빈 컴포넌트 데이터만 제거했다. Unity MCP로 실제 씬 컴포넌트를 재확인하고 수정 APK의 초기화·실행 로그에서 경고가 사라진 것을 확인했다.

최종 APK 빌드는 **성공, 오류 0, 경고 20**이었다. 기존 API/아이콘 등의 빌드 경고가 남아 있으며 무경고 빌드라고 판단하지 않았다. 첫 빌드의 생성된 Google 의존성 메타 파일 기록 오류는 다음 빌드에서 재발하지 않았다. 빌드가 자동 변경한 의존성·렌더링·프로젝트 설정은 작업 전 내용으로 복구했다.

## 화면과 입력

한 대의 실제 기기에서 Android 표시 크기·밀도를 아래 조건으로 바꿔 앱을 재시작했다. 각각 Unity가 보고한 실제 렌더 해상도를 대조했다. 여러 모델의 실기기를 검사한 것은 아니다.

| 조건 | 실제 렌더 해상도 | 밀도 | 상단 안전 영역 | 배치·계정 버튼 터치·뒤로가기 |
|---|---|---|---|---|
| 원래 기기 설정 | 1080×2316 | 450dpi | 67px | 통과 |
| 작은 휴대폰 조건 | 720×1280 | 320dpi | 45px | 통과 |

| 넓은 화면 비율 조건 | 1440×1600 | 420dpi | 89px | 통과 |

Android가 실행 중 표시 크기 변경에 호환 모드를 적용해 재시작을 요구하므로, 그 상태의 값을 다른 해상도 테스트로 세지 않았다. 위 표는 재시작 후 크기와 밀도가 실제 적용된 실행 결과다. 진짜 폴더블의 힌지·펼침 이벤트와 다른 GPU의 동작은 검증 범위 밖이다.

- 한영 로고와 안내 전환, 계정 버튼, 배경 탭의 미인증 진입 게이트, 바깥 탭 닫기를 확인했다.
- 실제 Android 입력으로 로그인 열기/뒤로가기 10회, 언어/연출 전환 각 10회를 반복했다. 뒤쪽 배경으로 입력이 새지 않았다.
- 연출 끄기에서 검이 중립 자세로 멈추고, 켜기에서 다시 움직였다.
- 홈 화면으로 이동했다가 복귀한 뒤 같은 프로세스에서 언어 설정과 연출이 유지됐다. 백그라운드 안정 구간 10초에서 프로세스 CPU 증가량은 1틱이었다.
- 최종 초기화 및 2분 연속 실행의 앱 로그에 Unity 예외·Missing Script가 없었다. Vulkan 초기화의 작은 포맷 탐색에 대한 드라이버 로그는 별도로 남아 있지만, 실제 텍스처와 렌더 동작은 정상 확인했다.

## 실측 성능

1080×2316에서 측정했다. 입력·화면 캡처·메모리 덤프를 실행하지 않는 안정 구간이며, 앱 내부 명령 파일 확인과 결과 직렬화는 측정 동안 중지했다. 마지막 2분은 수정 APK에서 다시 측정했다.

| 모드 | 시간 | 평균 FPS | 프레임 P99 | 최대 프레임 시간 | GC 할당 합계 | 드로콜 |
|---|---:|---:|---:|---:|---:|---:|
| 연출 켜짐 | 45초 | 60.03 | 16.70ms | 16.82ms | 0B | 13 |
| 연출 꺼짐 | 30초 | 60.09 | 16.70ms | 20.23ms | 0B | 13 |
| 절전 모드 | 30초 | 30.05 | 33.43ms | 33.70ms | 0B | 13 |
| 수정본 연속 실행 | 120초 | 60.10 | 16.69ms | 17.09ms | 0B | 13 |

최종 연속 구간 **7,207프레임**에서 33.5ms 초과 프레임은 **0개**였다. Unity가 계측한 총 할당 메모리는 120,177,831 → 120,185,111바이트로, 2분 동안 **7,280바이트** 증가했다. 이 짧은 측정에서 누적 증가 징후는 관찰되지 않았으며 무기한 메모리 안정성을 보장하는 검사는 아니다.

- Android 전체 프로세스 PSS: **432.0MiB**. Unity 할당 메모리와 서로 다른 지표이며 Development 빌드 코드·엔진·그래픽 드라이버 등을 포함한다.
- 실제 로비 `Atlas_UI`: 2048² ASTC 6×6 텍스처 2장, readable OFF. 텍스처별 런타임 크기 1,883,101바이트, 합계 **3,766,202바이트**. 기존 UI도 포함한다.
- 배터리 온도: 시작 **31.8°C**, 최종 **36.1°C**. USB 연결·충전 상태이므로 배터리 소모량 측정으로 해석하지 않는다.
- Main Thread 기록에는 프레임 대기 시간이 포함돼 실제 CPU 작업 시간으로 사용하지 않았다. 별도 GPU 실행 시간과 Release 빌드는 이번 실측 범위 밖이다.
