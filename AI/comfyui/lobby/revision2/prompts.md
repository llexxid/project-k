# 이미지 수정 지시 기록

내장 ImageGen의 모델/시드는 도구가 노출하지 않는다. 아래는 요청의 제작 지시를 정리한 기록이다.
모든 입력/출력은 `source/`에 보존한다. 제공된 상용 게임 스크린샷은 생성 입력에 사용하지 않았다.

1. **Background_Siege.png** — 기존 `Background_Clean.png`의 구도·숲길·색·그림체를 유지. 실제 MageTowerEnv.png를 마탑 정체성 참고로 사용. 먼 왕성을 부분 붕괴/화재로 바꾸고, 용 실루엣 두 마리와 돌 마탑 두 개의 청색 마법 사격을 추가. 원경에는 세밀한 얼굴이나 해부학 디테일을 넣지 않음. 전경 인물·글자·UI 없음.
2. **Knight_Master.png** — 기존 기사의 후면 3/4 달리기, 버킷 헬멧·흰 깃털·파란 망토와 의상 유지. 방패 완전 제거. 오른손에 넓고 대칭적인 은색 대검, 긴 갈색 손잡이, 단순 청동 가드. 검 끝까지 프레임 안에 유지. 투명 배경 요청 결과가 RGB 체크무늬로 출력되어 Comfy로 실제 알파 분리.
3. **Archer_Master.png** — 기존 궁수의 후면 달리기·머리·의상·화살통 유지. 활은 하나로 이어진 휜 목재 활대, 중앙 손잡이, 양쪽 끝을 잇는 하나의 팽팽한 시위. 손잡이 위아래 활대가 명확히 보이도록 교정. 마젠타 단색 배경.
4. **Background_Siege_Final.png** — 실제 첫 Unity 캡처를 맥락 참고로 제공. 제목이 원경 용을 가리는 문제를 수정하기 위해 공성 장면을 배경 높이 35~45%의 낮고 좁은 수평 영역으로 재구성. 용은 무너진 성벽 근처에서 날개를 수평으로 펼침. 마법 사격·연기 모두 해당 영역에 집중. 전경 숲길 유지.
5. **BanditKing_Final.png** — Comfy Bandit King 초안의 얼굴·왕관·복면·흉터·몽둥이 유지. 배경 숲과 같은 어두운 청록색 잎으로 가슴·어깨·팔 대부분을 가려 수풀에서 엿보는 형태로 변경. 머리/왕관/얼굴/몽둥이/일부 손가락만 노출. 매끈한 흉상 절단선 대신 자연스러운 잎 외곽, 마젠타 단색 배경.

Comfy Bandit King 초안은 실제 `Bandit King Sprite Sheet_0`(160×96)의 알파 영역을 정수배 NEAREST 확대한 참조와 기사 그림체 참조를 함께 입력했다. 왕관·대머리·회색 구레나룻·버건디 복면/망토·몽둥이와 비대칭 의심 표정을 명시했다.
기사 분리는 몸체와 대검을 든 팔을 정확한 원위치에서 각각 추출하도록 요청했으며, 모든 실제 지시·시드·포트는 API JSON에 있다.
