# 장비 강조 범위 수정 · 마탑 안내 검증

2026-09-21, Unity 6000.3.21f1, 기능 버전 0.17.0, Android versionCode 60 유지.

## 변경과 발견 문제

- 장비 안내가 장비 수에 따라 커지는 콘텐츠 루트를 가리켜 전장 전체를 강조했다. `ArmyEquipment`를 실제 스크롤 viewport에 연결하고 View에서 활성 조상 RectMask2D와 강조 영역의 교집합을 사용한다. viewport 자체에는 자동 중앙 스크롤이나 테두리 확대를 적용하지 않는다.
- `guide_mage_tower` SO를 만들고 bootstrap 카탈로그에 연결했다. 실제 마탑을 탭한 뒤 목록·장착·해제 설명을 확인한다. 소유 스킬이나 장착은 바꾸지 않는다.
- 순차 안내에서 이전 패널의 퇴장이 끝나기 전에 다음 대상이 나타나는 문제를 확인해 퇴장 시간 동안 표시를 기다린다.
- 마탑 하단은 파티 HUD에 가려져 상단 성벽을 강조한다. 원래 버튼과 실제 짧은 탭 이벤트를 사용한다.
- 마탑은 하위 Canvas이므로 기존 루트 Canvas만 검사하던 입력 필터가 탑을 거절했다. 현재 UI 루트의 하위 Canvas까지 검사하고 정렬·깊이로 가림을 판정한다. 재사용 목록은 안내 비활성화 때 비운다.

## 검증 결과

최종 전체 PlayMode 검사 **331개 통과**, 실패 없음. 상세 결과는 [acceptance.json](acceptance.json).

- 장비 48개가 있는 실제 UI에서 상단·중간·하단 스크롤과 viewport 내부 강조 범위를 확인했다. 실제 EventSystem 드래그도 통과한다.
- 기존 육성·왕국군·던전·뽑기와 새 마탑의 FIFO 실행, 완료 후 재요청 억제를 확인했다.
- 실제 마탑 포인터 누름/뗌으로 팝업을 열었다. 미보유 상태로 네 단계를 완료했고, 장착 상태에서는 활성 해제 버튼의 입력이 차단됨을 확인했다.
- 마탑 중간 취소·재요청 시 미확인 설명과 팝업을 복원한다. 로딩 중 입력 해제, 뒤로가기 시 건너뛰기 저장과 팝업 정리, 소유·장착·재화 보존을 확인했다.
- 기존 안내 저장 실패·지급 중복 방지·강화 및 뽑기 성공 거래·계정 전환·환생 설명 회귀가 통과했다.
- Editor 컴파일 오류 없음. bootstrap의 기존 6개와 새 마탑을 포함한 SO 7개가 모두 연결되어 데이터 검증을 통과했다. 작업 종료 시 저장된 bootstrap 편집 씬으로 복원했다.

최종 실행의 Editor 전체 렌더 통계는 장비 단계 33–38 batches/draw calls, 마탑 단계 26–34다. 총 할당 메모리는 약 473–478 MB이며 Editor 전체의 시점 값으로, 이 기능의 증분 메모리나 기기 성능 수치가 아니다. 반복 검사의 원시 로그는 [interactive-render.txt](interactive-render.txt)에 보존한다. 기존 폰트·스프라이트·팝업을 재사용하며 새 텍스처는 없다.

검사는 격리 계정과 실제 UGUI 프리팹, 합성 포인터 입력을 사용한다. 실전 전투 성능·APK·Android 기기 검증은 수행하지 않았다. 커밋·푸시·빌드·기기 설치도 실행하지 않았다.
