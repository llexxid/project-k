# 실습형 기능 안내 검증 — 0.16.0

Unity 6000.3.21f1에서 컴파일 및 격리 계정 PlayMode 검사 **270개 통과**. 세부 결과는 [acceptance.json](acceptance.json)에 기록했다. 실제 UGUI 프리팹·SO와 EventSystem 레이캐스트/드래그, 기존 강화·뽑기 거래 API를 사용했다.

## 확인 범위

- 기존 하단 설명·환생 미리보기, 단계 저장, 완료·건너뛰기 재요청 억제, FIFO·중복 요청.
- 네 실습의 전체 진행과 정상 종료 후 메인 복귀. 강화는 정확히 1회, 뽑기는 기존 확률의 장비·마탑 분류별 1회.
- 고대주화 50개씩 두 번 지급과 100개 소비, 지급 재호출의 멱등성, 저장 실패 시 주화·획득·영수증 롤백.
- 소비 성공 직후 안내 단계 저장 전 중단 상태에서 재소비 없이 재개.
- 골드 부족 시 추가 지급 없이 미완료 유지, ‘나중에 계속’, 최대 강화 대체 확인.
- 실제 경제 저장 실패 후 입력 해제와 재요청, 실행·대기 중 계정 전환과 이전 실행 세대 폐기.
- 팝업·로딩·대상 숨김/파괴·메인 재생성·Manager 비활성화 복구, 저사양 설명·터치 유지.
- 허용 버튼 클릭, 관계없는 메뉴 차단, 10회 강화·결과 확인 전 추가 뽑기 거절, 전직 정보 화면의 실제 드래그.
- 실제 오버레이 직렬화 참조, SO 유효성, bootstrap 연결.

## 화면과 비용

360×800, 540×960, 900×1200은 **Editor RenderTexture 비율 시뮬레이션**이다. 안내 본문 넘침과 안전 영역을 검사했다. 실습은 강화·장비 정보·전직 비교·루비 상세·장비 뽑기를 각 비율로 캡처했다. 주요 캡처:

- [왕국군 장비 설명](guide_kingdom_army-equipment-360x800.png)
- [전직 비교](guide_kingdom_army-job_stats-540x960.png)

- [장비 뽑기 실습](guide_gacha-equipment_once-360x800.png)

`interactive-render.txt`에는 실행별 Editor 통계가 누적되어 있다. 마지막 검사에서 UI fixture의 draw calls/batches는 33~36, 총 Unity 할당 메모리는 약 445~449 MiB였다. 이는 Editor·fixture·캡처를 포함하는 값이며 안내 단독 비용이나 Android 측정치가 아니다. 새 텍스처·폰트·머티리얼은 추가하지 않았고, 입력 필터는 포인터 조회 때만 그래픽을 검사한다. 변하지 않은 본문과 레이아웃은 재작성하지 않는다.

## 발견·수정·재검증

1. 입력 필터 안에서 EventSystem.RaycastAll을 중첩 호출하는 방식은 UGUI 공유 정렬 자료를 교란할 수 있어 제거했다. 같은 Canvas의 Graphic과 마스크·CanvasGroup을 직접 검사한다. UGUI IndexedSet은 열거자를 지원하지 않으므로 인덱스로 순회한다.
2. 로딩 복귀 검사에서는 활성화 직후 Canvas 레이캐스트 등록을 기다린 뒤 실제 클릭하도록 테스트를 보완했다.
3. 미구현 던전 카드가 루비 대상 ID를 덮던 문제를 수정했다. 골드·루비 종류만 등록한다.
4. 패널 등장 중 버튼이 마스크 밖에 있는 시점에 안내가 먼저 뜨던 문제를 수정했다. 기존 unscaled 슬라이드가 끝난 뒤 표시한다.
5. 최종 전체 검사에서 위 경로와 저장 복구를 재검증했다. 의도적으로 유발한 저장 실패 오류는 결과 JSON의 성공 검사에 포함되며 실제 사용자 저장은 사용하지 않았다.

## 범위 밖

자동 발생 조건, 컷씬, Excel, 실제 로그인 흐름과 장시간 전투 성능, Android 빌드·실기기 입력은 이번 검사에 포함하지 않았다. 안내가 Time.timeScale을 바꾸지 않는 것은 검증했으며 실제 전투 캡처로 표시하지 않았다. 커밋·푸시·APK 빌드·기기 설치는 실행하지 않았다. PlayerSettings 버전은 0.16.0, Android versionCode는 60을 유지한다.
