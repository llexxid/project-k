# 오프라인 광고 보상 검증 — 2026-10-28

Unity 6000.3.21f1, 게임 0.17.0. 기존 기본 보상 선지급을 유지하고 오프라인 선택·광고 보너스·최종 결과를 연결했다. Google 보상형 테스트 ID만 사용한다.

## 결과

- 컴파일 오류 0. 실제 프리팹의 광고/수령/결과 확인 버튼 참조와 기존 Galmuri11 SDF 폰트를 확인했다.
- [핵심 검사 14개 통과](core-checks.json): 선지급, 원본 금액 보존, 정확한 추가 골드·EXP와 레벨 상승, 처치·퀘스트 불변, 원자적 저장 실패·재시도, 중복 방지, 미발급 정산 거절, 계정 전환, 저장 재오픈, 광고 복귀 원인 유지.
- [UI 검사 13개 통과](ui-checks.json), [실행 스크립트](ui-acceptance.cs): 완료 후 저장 실패 → 다음 정산 도착 → 광고 없이 지급 재시도 → 이전 결과 → 대기 정산, 강제 정리, 일반 결과의 설명 영역 숨김, 기존 일반 재화 팝업 호환.
- 실제 bootstrap 로그인 후 main 전투와 메뉴가 표시된 상태에서 검증했다. 프레임 증가를 확인한 뒤 재화 비교 중에는 전투 시간만 정지했다. 보상 검증은 별도 `balance-qa-offline-ad-ui-20261028` 로컬 프로필에서 수행하고 원래 계정·시간·GameView 설정을 복원했다.
- Editor Google SDK 모의 광고를 실제로 열고 완료 콜백 후 닫았다. 기본 1,200 골드/360 EXP → 추가 1,200 골드/360 EXP, 최종 2,400 골드/720 EXP 표시를 확인했다. 광고 준비 중 중복 호출과 두 버튼 잠금도 확인했다.
- 중단은 보상 콜백 전 SDK의 숨겨진 닫기 버튼 이벤트를 주입해 검사했다. 광고 실패는 서비스 실패 콜백 주입, 저장 실패는 기존 `TestFailedCommit` 도구로 검사했다. 이들은 실제 기기의 네트워크 장애·사용자 탭 재현과 구별한다.
- 배경 버튼 이벤트와 `UIManager.RequestBack()`으로 선택창이 유지됨을 확인했다. 정상 수령은 추가 지급하지 않는다.

## 화면과 비용

GameView 자체를 360×800, 540×1200, 768×1024로 변경했다. 같은 Editor의 비율 검사이며 여러 실제 기기를 검사한 것은 아니다. 한글·버튼 문구·보상 합계에 잘림이 없고 일반 결과의 빈 설명 영역이 제거된다. 좁은 화면에서 버튼이 작아 높이를 112→144 논리 픽셀로 보정했다. 최종 선택 버튼은 360px 너비에서 148×48px이고 TMP overflow가 없다([측정](layout-check.json)). 실제 프리팹과 생성 코드 모두 144로 저장했다.

기존 텍스처·아이콘을 재사용하며 새로운 아트/아틀라스/폰트는 추가하지 않았다. 선택창에서 측정한 Editor 전체 게임 렌더링은 37 batches/활성 Graphic 167개다. 변경 전 성능 기준값과 실제 Android CPU/GPU·메모리는 측정하지 않았으므로 개선 수치로 해석하지 않는다. 화면 전체 safe area를 검사했으며 실제 노치·내비게이션 영역은 기기 검증이 필요하다.

## Android 및 남은 범위

Android 실제 게임 테스트 APK 빌드 결과는 완료 후 이 기록에 반영한다. 현재 `adb devices`에 연결 기기가 없다. Editor 모의 광고 성공은 실제 Android 광고 영상·Activity 복귀·저장 검증을 대신하지 않는다.

강제 종료 후 미지급 광고 보너스 복구는 합의대로 제외했다. 저장된 기본/추가 보상은 유지된다. 운영 광고 ID·미디에이션·서버 보상 검증·일일 광고 재화는 포함하지 않았다.
