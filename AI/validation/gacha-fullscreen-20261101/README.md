# 전체 화면 뽑기 검증 — 0.20.0

Unity 6000.3.21f1, Windows Editor. 실제 Android 기기는 ADB 목록에 나타나지 않아 기기 실행·설치·성능 검증을 완료하지 못했다. 이후 사용자의 “빌드는 하지마” 지시에 따라 진행 중이던 Android 빌드를 중단했으며 재시도·설치는 하지 않았다. 아래 비율 검사는 한 Editor의 Game View 변경이며 여러 실제 기기 검증이 아니다.

## 구현 및 원본

- `Panel_Gacha_Old`는 보존 커밋 `12c67f8b`의 원본과 비교해 루트 이름만 변경됐다. GUID `aafa5a61c0637984c8fc08ba01709101`, 나머지 구조·참조 및 기존 콘텐츠 프리팹은 유지했다.
- 새 `Panel_Gacha`는 새 GUID와 카탈로그 진입점을 사용한다. SafeAreaFitter 추가 없이 기존 `SafeArea/LayerPanels`를 채운다. 루트·본문 Stretch/Offset 0, 메인 ScrollRect·SheetSizeFitter·SheetClip 없음.
- fullScreen 플래그에서 위치·크기 강제 변경을 건너뛰고 0.15초 unscaled 페이드만 사용한다. 퇴장 중에도 뒤의 입력을 가리고 비활성화 이후 PartyHudSuppressor를 반환한다.
- 보상 목록은 팝업을 열 때만 기존 카드를 만들고, 기존 모달 뒤로가기 처리와 소유 패널 수명을 따른다. 기본 아트·재화 아이콘·폰트·테마는 기존 에셋을 재사용했다.

## 통과한 검사

`ui-validation.json`은 정상 로그인 후 수행한 UI 검사다. `GachaFullScreenValidation.Run()`으로 재실행한다.

- 720×1280, 1080×2400, 1536×2048에서 모든 본문 행과 글자가 잘리지 않는다. 1080×1920에 상단 5%·하단 3.5% 안전 영역을 모의 적용한 경우도 통과했다.
- 등장 중 위치 불변, 스택에서 재노출 후 알파·입력·위치 복구, 3회 빠른 열기/닫기 후 억제 카운터 0을 확인했다.
- 왕국군 HUD 및 실제 수동 시전 HUD의 비노출·입력 차단, 종료 후 두 HUD 복원을 확인했다. 하단 메뉴 위치의 Raycast가 뽑기에 가로막힌다.
- 장비 13개 항목(장비 12·파편 1), 마탑 11개 항목(스킬 8·지식 3), 모든 보상 아이콘, 보상 팝업 스크롤, 뒤로가기, 탭 보존, 원본 패널 종료 시 팝업 정리를 확인했다.
- 서버 DTO 누적값 0·38·39·0·7에 대한 `N / 40회`, 남은 횟수, fillAmount 표시 fixture가 통과했다. fixture는 같은 프레임의 메모리에만 적용하고 즉시 복원하며 저장·서버 요청은 하지 않는다.
- 재화 부족 시 버튼 비활성화·`고대주화가 50개 부족합니다.` 안내와 보관함 포화에서도 CanPullMulti 허용을 메모리 fixture로 확인했다(`admission-fixture.json`). 실제 서버의 가득 찬 보관함 거래를 수행한 것은 아니다.

## 실제 서버 거래

타이틀의 기존 게스트 로그인 UI를 사용했다. 기존 개발 게스트 인증 구현을 변경하거나 새 계정을 강제 지정하지 않았다. 로그인 대기 시간 초과가 발생했으나 재시도 후 정상 진입했다.

| 조작 | 고대주화 | 최종 천장 | 결과 |
|---|---:|---:|---|
| 장비 10회 버튼 연속 2회 호출 | 14,520 → 14,020 | 26 → 5 | 거래 1회, 결과 10개, 중간 에픽 후 최종 누적 갱신 |
| 결과창의 다시 1회 | 14,020 → 13,970 | 5 → 6 | 결과창·본문 천장 함께 갱신 |
| 마탑 1회 버튼 연속 2회 호출 | 13,970 → 13,920 | 6 유지 | 거래 1회, 비전 지식 20개 |

`live-gacha.json`에 서버/로컬 최종 상태 로그를 보존했다. 뽑기 버튼과 결과 확인 버튼의 가이드 대상 등록도 확인했다. 가이드 전체 실습을 새 계정에서 다시 수행한 것은 아니다.

같은 Editor의 전체 게임 60프레임 표본이다. 전투·Editor 비용을 포함하므로 모바일 성능이나 UI 단독 GC로 해석하지 않는다.

마지막 재검사 수치이며 첫 통과 캡처·측정은 `Recordings/Gacha20261101/initial-pass`에 보존했다. 전체 게임 GC 표본은 증가했으므로 GC 개선을 주장하지 않는다. 새 텍스처를 만들지 않았고 기존 상자 도트 스프라이트를 `Atlas_UIPixel`의 기존 Point/ASTC 설정에 포함했다.

불투명 배경으로 전투 비침을 제거하고, 확대된 메뉴 아이콘을 기존 Point 도트 아트로 교체했다. 천장 설명의 1px 높이 부족을 8px 여유로 수정했다. 보상 카드는 모바일 3열로 넓혀 읽기 쉽도록 했다. 검증기에서 뒤로가기를 거절하는 접속 보상창의 무한 반복을 발견해 정상 확인 버튼과 횟수 제한으로 고쳤다. Editor 재시작 시 씬 백업은 `Recordings/Gacha20261101/Recovery`에 보존했다.

전후 캡처는 이 폴더, 전체 비율·팝업·실행 캡처는 `Recordings/Gacha20261101`에 있다. 취소된 빌드 시도는 0.20.0 b67이며 APK는 생성되지 않았다. 시도 번호 67은 유지하고 빌드의 임시 패키지명·제품명·ABI·Gradle·렌더링 설정 변경은 복원했다. 중단 로그는 `Recordings/Gacha20261101/Android`에 보존했다.
