# GameTest 안내 기록 초기화 검증

Unity 6000.3.21f1에서 컴파일 및 전체 PlayMode **350개 검사 통과**. 결과는 [acceptance.json](acceptance.json).

## 제공 메뉴

PlayMode에서 `GameTest → Guide Test/실제 계정 저장/다섯 안내 테스트 기록 초기화 (재지급 허용)`를 실행한 뒤 개별 또는 순차 실행한다.

사용자가 확정한 범위는 육성·왕국군·던전·뽑기·마탑의 안내 진행, 실습 성공 기록, 체험 주화 지급 기록이다. 현재 재화·강화·장비·스킬 소유 내역은 유지한다. 이후 실습은 다시 소비·획득하며 주화도 재지급하므로 보상은 누적될 수 있다. 환생·다른 안내·퀘스트의 기록은 지우지 않는다.

## 검증 항목

- 실제 ContextMenu 메서드를 호출해 실행 중 안내·대기열·입력이 정리되는지 확인했다.
- 다섯 안내의 진행·실습·지급 키만 제거되며 유사 ID 및 무관한 기록은 보존된다.
- 초기화 전후 재화·강화 수치·보유 장비·마탑 스킬 및 장착 상태가 같다.
- 저장 실패를 주입하면 진행·실습·지급 기록 모두 기존 상태로 롤백된다.
- 완료했던 뽑기를 첫 단계부터 다시 요청하고, 체험 주화 50개 재지급 및 실제 뽑기 재시도 허용을 확인했다.
- 기존 다섯 안내, 저장 실패·계정 전환·재개, 하이라이트 표시 회귀 검사가 통과했다.

초기화 코드와 메뉴는 `UNITY_EDITOR`에만 포함된다. 실제 사용자 계정을 초기화하지 않고 격리 계정과 실제 UI 프리팹으로 검사했다. 커밋·푸시·APK 빌드·기기 설치는 수행하지 않았다.
