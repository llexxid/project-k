## 실제 수행한 검증

- Word 원본 추출 및 개정 문서 35페이지 PDF 렌더. 전 페이지 시각 검수와 텍스트 경계 검사.
- 기본 render_docx.py는 LibreOffice 미설치로 실패. 숨김 Microsoft Word COM ExportAsFixedFormat 및 임시 설치 PyMuPDF로 대체했다.
- artifact-tool로 엑셀 저작. 원본 OOXML에 신규 시트/명시된 셀 변경만 조립해 기존 테이블·병합·ID를 보존.
- Stage 원본 워크시트/테이블 관련 XML 16개는 바이트 단위로 동일.
- Microsoft Excel에서 두 파일 정상 열기, 전체 재계산, 수식 오류 0개 확인. 캐시 값을 최종 파일에 반영.
- 별도 Decimal 계산으로 메인 33웨이브, 던전 5단계, 골드 0~300/마탑 0~100/루비 0~50 비용·누적 검증.
- 가이드 28개 체인, 보상 그룹 참조, 필수 TargetId, 폐기/보류 상태, 일일·주간 보상 합계 검증.
- 카탈로그 7개 시트와 베타 시트의 주요 모든 구역 렌더 검수.
- 현재 StageDatabaseSO 32개 레코드와 원본 정의의 수량·배율·제한시간·활성 비교: 차이 0개.
- 입력 파일 4개 해시 보존. 조사한 자체 C# 343개 중 작업 중 변경 감지 0개.
