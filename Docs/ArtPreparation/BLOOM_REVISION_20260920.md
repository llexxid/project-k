## 저장·로스터

활성 스킬은 8종, ID 0–5·7·9이며 각각 전체 뽑기의 6.25%다. ID 8을 새 스킬에 재사용하지 않고 독립 운석의 뽑기·장착·시전 진입을 차단했다. 에셋 원본은 재사용과 이력 보존을 위해 남겨둔다.

기존 운석과 유성우의 높은 강화·각성을 남기고, 겹치는 강화의 실제 지출을 비전 지식으로 전액 환급한다. 겹치는 각성에 사용한 누적 파편과 남은 파편을 합산하며, 둘 다 보유했다면 중복 보유분 30파편을 추가한다. 기존 내역과 환급 근거는 `mage-meteor-merged-v1`에 보관한다. 장착된 운석은 유성우가 다른 슬롯에 없으면 유성우로 교체하고, 이미 있으면 중복 슬롯만 비운다. 기존 운석이 장착되어 있고 통합 후 각성 10이면 메테오 형태를 보존한다.

순수 변환뿐 아니라 실제 저장 파일을 열어 변환·환급·이력 보관이 함께 기록되는지, 다시 열어도 환급이 중복되지 않는지 검사했다. 실제 사용자 저장은 진단 실행 전 PC에 백업했다. 진단 계정 외 원본 파일 54개가 바이트 단위로 동일한 것을 확인한 뒤 이번 진단 파일 300개와 새 진단 프로필 파일 4개를 제거했다.

## 아트·UI 검수

10개 아이콘을 기존 도트에서 파생하고 실제 Comfy Cloud 색상·16색 양자화 공정으로 마감했다. 최종 아이콘은 48px, 불투명 색 4–11개, 알파 0/255다. 일반 라이트닝은 세 가닥, 천벌은 기존 뇌운에 보랏빛, 만년빙정은 여러 송곳과 큰 빙정, 메테오는 운석과 뜨거운 균열을 표현한다. 다른 개화들도 기존 효과를 유지하면서 더 밝은 외곽 효과를 표시한다.

유성우 원본 애니메이션의 형태는 유지했다. 붉은 세 색과 8프레임 타원 파동을 적용했다. 메테오는 기존 갈색 지면에 16프레임의 얇은 붉은 균열을 분리해 은은한 맥동을 넣었다. 실제 폰에서 전투원 발·체력바·수동 시전 버튼을 가리지 않는지 확인했다. 원본 ExternalAssets는 변경하지 않았다.

발견하여 수정한 문제:

1. 최초 흔들림 연결은 원근 카메라를 제외해 실제 흔들림이 0이었다. 카메라의 착탄 깊이에서 픽셀 크기를 계산하도록 수정하고 Editor·Android에서 실제 이동량을 측정했다.
2. Comfy 양자화 출력의 RGB 변환으로 일부 아이콘 배경이 검게 나타났다. 입력 도트의 정확한 알파 마스크를 복구했다.
3. 상세 메뉴가 개화 이름·아이콘만 바꾸고 기본형 설명을 표시했다. 개화 메커니즘 요약으로 바꾸고 최종 피해 표시에도 실제 개화 계수를 적용했다. 메테오는 충돌·장판, 만년빙정은 단일·다수 피해를 구별한다.
4. 기존 피해 설명이 한 줄 높이에 두 줄을 넣어 잘렸다. 상세 프리팹의 스탯 행을 내용 높이에 맞춰 늘리고 줄바꿈을 허용했다.

## 실행 검증

- Editor 실제 Play Mode 14사례, 오류 0. 일반 낙뢰 3/5회, 천벌 단발, 얼음 개화, 유성우, 메테오, 나머지 모든 개화 및 흔들림 OFF 검사.
- 최종 Editor 수용 검사 204개 통과. 초기 Android 진단 빌드에서는 202개 통과했으며 이후 추가한 2개는 저장 파일 재개방에 대한 검사다.
- 유성우 첫 착탄 내부 2체만 피해, 바깥 대상 제외. 발사 시 정한 위치와 18개 모든 착탄 위치 일치.
- 메테오 첫 피해 약 1.617초, 실제 장판 지속 3.5초. 장판 내 감속 0.60, 벗어나면 기존 독 감속 0.25로 복구.
- 8개 스킬 모두 실제 개화 버튼 ON/OFF, 아이콘·이름 전환 확인. 시전 중 전환해도 이미 진행 중인 효과와 쿨타임은 유지.
- Android 실제 드래그: 기본 유성우는 쿨타임 미소비, 개화 메테오는 지점 시전 성공.
- 화면 흔들림 ON: 일반 3/5회, 천벌·메테오 1회씩. OFF: 기록 0회, 실제 카메라 이동량 0.
- SM-N986N 한 기기에서 720×1280, 1080×2400, 1200×1600 표시 비율을 검수하고 원래 1080×2316으로 복구했다. 서로 다른 실물 기기 검증으로 간주하지 않는다.

## 최종 앱 확인

진단 빌드 b57과 실제 플레이 빌드 **0.14.0(b58)** 모두 IL2CPP 빌드 성공, 오류 0이다. 각각 88개의 경고가 있으며 Google Play Games의 폐기 예정 API 등 기존 경고를 포함한다. 최종 b58에는 진단 프로브·강제 테스트 계정이 없다. 정상 게스트 로그인, 전투, 스킬 편성, 상세 설명, 실제 개화 버튼 OFF/ON, 뒤로가기, 수동 메테오 시전을 실제 기기에서 확인했다.

기존 장비 **90개 모두 보존**, 골드 강화·루비 강화·환생 수준 보존, 12장 진행 유지가 확인됐다. 기존 운석 슬롯은 메테오로 전환됐으며 유성우 파편은 365에서 두 스킬의 보존분을 합친 875로 증가했다. 메테오 상세의 충돌 19.04K·장판 1.9K 표시가 실제 전투의 피해 표시와 일치했다. 기본형으로 끄면 이름·아이콘·설명·피해 952·쿨타임 8초로 전환되며, 다시 켜면 메테오·쿨타임 12.8초로 돌아왔다. 피해 설명은 잘리지 않았다.

프로젝트 앱은 기기에 한 개만 남겼고 b58이 설치되어 있다. 진단 파일 잔존 0, 최종 프로세스의 런타임 예외 0이다. 이번 화면 녹화의 기기 원본과 사용이 끝난 PC 진단 APK를 제거했으며, 최신 플레이 APK와 증거 캡처·PC 저장 백업은 보존했다. `final-device.json`, `save-preservation.json`, `build.txt`, 최종 상세·타격 캡처가 근거다.
