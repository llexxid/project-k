## 확률·파편·개화

- 1회 50코인. 스킬 전체 50%, **10종 각각 5%**. 비전 지식 10/20/50개는 각각 30/15/5%.
- 최초 획득은 해제, 중복은 **각성 파편 30개**. 스테이지 최초 클리어의 원래 파편 보상과 구별합니다.
- 각성 0→10에는 55파편. 미보유 스킬은 같은 스킬 3회 획득이 필요합니다.
- 특정 스킬의 평균은 60회, 주 21회를 모두 마탑에 쓰면 약 **2.86주**. 90% 도달은 105회, 약 **5주**입니다. 이미 보유한 스킬은 평균 40회입니다.

음이항 분포로 계산했으며 천장이나 최초 클리어 보너스를 포함하지 않습니다. 평균은 보장 기간이 아닙니다. 장비 뽑기에 재화를 나누면 더 오래 걸립니다. [계산 근거](Validation/MageIntegration/investment.json)

**천벌:** 뇌운을 모아 큰 범위에 거대한 벼락을 내립니다. 피해 1000% · 준비 약 2초 · 재사용 대기시간 2배. 최대 10대상이며 월드 반경에 상한·하한을 둡니다. 플레이어 툴팁에 기기마다 달라지는 ‘화면의 절반’ 표현을 쓰지 않습니다.

**만년빙정:** 여러 적에게 송곳 8개를 두 번 생성하며 각각 피해 50%. 적 하나에게는 거대 빙정의 피해 650%와 기절 2초. 저사양은 동시에 표시하는 송곳만 8→4개로 줄이고 타격 판정은 유지합니다.

각성 10에서 개화를 켜고 끌 수 있습니다. 켜면 같은 스킬의 형태를 유지한 변형 아이콘을 목록·상세·장착 슬롯에 표시합니다. 선택은 저장되며 진행 중 시전에는 영향을 주지 않고 다음 시전부터 반영됩니다. 쿨타임 중 장착 교체로 대기시간을 우회하지 못합니다. 나머지 8종은 사용자 지시대로 전용 기믹을 보류하고 `개화: 미정`으로 표시합니다.

기존 상세기획서 DOCX와 기획데이터 TXT에 확정 정책을 덮어썼습니다. DOCX 41페이지를 Word PDF/Poppler로 렌더링하고 변경 페이지를 재검수했습니다. 별도 운영용 사본은 만들지 않았습니다.

일반 번개·얼음·바위는 솟는 프레임에 피해 시점을 맞추고, 천벌과 운석은 준비 동작 후 타격합니다. 기존 효과음을 10종에 연결하고 피치·볼륨·풀 반환을 조정했습니다. 화면 전체 섬광이나 카메라 흔들림을 추가하지 않았습니다. 지속 독·성역·균열은 몸체 뒤에서 낮은 알파로 표시합니다.

뽑기 버튼은 어두운 목재·청동 9-slice와 0.48초의 잔잔한 청색 가장자리 불꽃을 사용합니다. 취소·이중 터치의 결제 원자성을 실제 터치로 검사했습니다. 목록의 셀 10개를 재사용하고 불필요한 텍스트·레이아웃 재생성을 줄였습니다.

아이콘은 48px 논리 크기·최대 16색·Point, 새 파생 VFX는 4–6색입니다. 아이콘은 UIPixel, VFX는 `Atlas_MageVFX`의 Point/ASTC 4×4/최대 2048을 사용합니다. 아틀라스 입력은 RGBA32로 두어 중복 압축을 피하고 mipmap/readable을 끕니다. Galmuri11은 453→864글리프, 기존 4096 아틀라스 1장을 유지합니다. 사용자 이름을 위한 동적 추가는 유지합니다.

### 자동 전투 성능

얼음 개화·화염·독·성역·균열을 5슬롯에 장착하고 각 20초를 측정했습니다. 합성 피해 fixture를 끄고 실제 전투를 사용했습니다. 성능 캡처에 팝업이 없는 것을 확인했습니다.

피해 숫자 처리 비용은 이 표본에서 약 56.5% 낮았습니다. 시작 조건은 같지만 몬스터 이동·랜덤 환경·진행이 다르므로 총 GC·Draw 차이를 모드 효과로 단정하지 않습니다. 무할당이 아니며 짧은 표본은 장기 누수나 실제 저사양 하드웨어 검증을 대신하지 않습니다. [전체 측정](Validation/MageIntegration/release-performance.json)

Android resolver의 Windows 파일 매핑 오류 1224는 빌드 전에 의존성을 확인·해결하고 중복 장면 해결만 해당 QA 빌드 동안 억제하는 방식으로 처리했습니다. `finally`에서 설정·패키지·ABI를 복구합니다. 외부 resolver 소스는 수정하지 않았습니다. BuildReport.totalSize는 실제 APK 크기가 아니며 `build.json`에 실제 파일 크기·SHA-256을 따로 기록합니다.
