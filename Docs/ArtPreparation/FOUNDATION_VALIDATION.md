# 작업용 아트·버전 표시 검증

검증일: 2026-09-15. Unity 6000.3.21f1, 게임 0.9.0, Android versionCode 2.

## 적용

- `Assets/ExternalAssets/`와 폴더 `.meta`를 Git에서 제외했습니다. 이전에 추적되던 47,105개 파일 모두 디스크에 남아 있음을 확인했습니다.
- UI/VFX용 원본 94개를 작업 폴더로 복사했습니다. PNG 바이트의 SHA-256 일치, 원본 meta GUID 보존, 복사본의 별도 GUID를 검사했습니다. 목록과 해시는 [runtime-art-copies.json](Manifests/runtime-art-copies.json)에 있습니다.
- 자체 프리팹·씬·SO·애니메이션·컨트롤러·SpriteAtlasV2 전체의 Unity 의존성 검사에서 ExternalAssets 참조는 0개였습니다. UI 이미지 검색기의 실제 존재하지 않는 `plus` 별칭은 원본 `add` 이미지로 바로잡았습니다.
- 버전 원본은 PlayerSettings.bundleVersion입니다. 로비의 안전 영역 좌측 하단과 공용 설정창에 표시합니다. 빌드 전 Unity 버전 파일과 실행 중 에디터 버전, 게임 버전 형식을 검사합니다.

## 실제 기기

Samsung SM-N986N / Android 13 / Adreno 650 / Vulkan / 1080×2316. 별도 QA 패키지에 업데이트 설치했으며 기존 게임 앱 데이터는 변경하지 않았습니다.

- ARM64 IL2CPP Development 빌드 성공: 1,338,743,278 bytes, 4분 35초, 오류 0.
- 로비에서 좌측 하단 `v0.9.0`, 로비 설정과 인게임 HUD 검증 환경에서 설정창 하단 `v0.9.0` 표시를 캡처했습니다. 기존 뒤로가기·스크롤 동작을 확인했습니다.
- 로비 10초 / 597프레임: 평균 60.09fps, 프레임 p95 16.67ms, 33ms 초과 0회. 평균 드로우 13.10, Unity 메모리 약 124MB. 개발 빌드의 프레임 대기와 진단 비용이 포함된 수치입니다.
- 해당 실행의 Unity 로그에서 실행 예외나 누락 참조가 발견되지 않았습니다. 스토어 아이콘 압축에 대한 기존 경고 12회가 있었습니다.

캡처·원시 수치는 로컬 `Recordings/CatalogIntegration/Foundation/Device/`에 보관합니다. 이 단계의 인게임 확인은 공용 HUD/설정 검증 환경이며, 새 몬스터·배경의 실제 전투 검증은 다음 적용 단계에서 진행합니다. 이번 소규모 표시 변경은 실제 기기 1대로 확인했으며 다른 기기나 화면비를 검증한 것으로 간주하지 않습니다.

## Git 범위

다운로드 원본의 추적 제거는 과거 Git 이력을 삭제하지 않습니다. 새 체크아웃은 게임용 복사본으로 실행할 수 있으며, 원본 제작 작업에 필요한 외부 팩은 별도로 내려받아 보관합니다. Android QA 빌드가 만든 기기별 resolver 설정·Gradle 백업·셰이더 전처리 캐시는 변경 결과에 포함하지 않습니다.
