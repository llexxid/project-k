선행 수정은 `79774fe5a`에 커밋한 뒤 시작했다. 연결된 SM-N986N 한 대에서 직접 터치로 플레이했고, 오류 수정·빌드·재설치 후 같은 경로를 다시 확인했다. 원시 기록은 `Recordings/PlayerSimulation`, 요약 증거는 `Validation/PlayerSimulation`에 보관한다.

## 시간과 데이터 구분

각 회차는 전면 실행·timeScale 1에서 게임 시간이 실제로 흐른 구간만 합산한다. 설치, 재시작, 백그라운드, 결과창 정지, 스킬 캡처 정지와 25초 이상 관측 공백은 제외한다. 서로 겹치지 않는 회차인지 `summarize_player_sessions.py`로 검증한다. Unity의 빠른 검사 시간은 이 합계에 포함하지 않는다.

검증한 인정 시간은 **1회차 1,809.10초, 2회차 1,802.47초, 3회차 1,807.00초**, 합계 **90분 18.58초**다. 정확한 시작·종료와 관측 제외 내역은 `Validation/PlayerSimulation/sessions.json`을 기준으로 한다.

- 1회차: 새 QA 계정의 자연 성장. 28개 가이드, 1~3장 및 보스, 골드/루비 강화·초기화, 전직, 장비·스킬, 던전, 첫 환생.
- 2회차: 같은 계정에서 재화 주입 없이 진행. 일일·주간·업적 보상, 장비 장착·강화·잠금·분해, 실제 뽑기, 스킬 강화·각성·개화·초기화, 두 번째·세 번째 환생, 재로그인·방치 보상, 설정별 성능.
- 3회차: 후반 접근 조건을 명시적으로 설정한 격리 QA 계정. 전체 스킬 기본/개화 20개, 정예 병과, 던전 전 단계, 보장 뽑기, 과밀 보관, 화면 비율 검사. 주입한 자원과 성장 수치는 자연 성장 성과로 계산하지 않는다.

## 성능과 남은 관측

실제 획득 장비 약 100개 상태에서 6초 표시 간격을 수집했다. 장비 메뉴 최대 66.53ms, 가방 66.72ms, 재방문 뽑기 74.94ms였다. 선행 수정 전 약 973ms 장비 메뉴 정지는 가시 카드 재사용으로 크게 줄었다. 보유량·배경 전투가 달라 엄밀히 동일한 벤치마크는 아니다.

첫 뽑기 메뉴에서 **2,578ms 간격을 한 번 관측**했다. 진단 빌드에 생성·배치·카드별 시간을 추가한 뒤 같은 기기 새 실행에서 분리 재검사했을 때 UI 구성 34.93ms, 최대 표시 간격 83.34ms였다. 긴 정지의 원인은 확정하지 못했으므로 해결 완료로 기록하지 않는다. 원본 측정과 진단 로그를 보존했다.

각 30초 일반/저사양/절전/동시 모드에서 약 59.56/59.73/29.85/29.95fps, 프로세스 CPU 단일 코어 환산 81.71/79.84/53.84/51.89%였다. 저사양의 피해 숫자 처리 시간과 프레임당 할당도 감소했다. 같은 전투 지점이지만 적·시전 시점이 같지 않으므로 보편적인 절감률로 일반화하지 않는다. `performance-modes.json`, `menu-performance.json`.

최종 b37의 원래 계정(장비 300개·개별 보관 100개)에서는 첫 뽑기 83.23ms, 장비 49.87ms, 가방 74.89ms가 최대 표시 간격이었다. 장비 메뉴의 50ms 초과는 0개였다. `final-menu-performance.json`. 이전 2.58초 관측은 그대로 남긴다.

## 플레이 가치 관점

돈을 쓰기 전에 성장과 보상이 믿을 만해야 한다. 이번에는 보상 보존, 보장 횟수, 실제 스탯, 명확한 환생 조건, 다음 목표 이동을 우선했다. 확률·가격·유료 상품은 임의로 바꾸지 않았다.

현재 일반 카탈로그는 3장까지여서 자연 성장 1회차 안에 마지막 보스까지 도달했다. 장기적인 결제 매력을 평가하려면 이후 목표와 반복 콘텐츠의 폭이 더 필요하다. 이번 90분 검증만으로 장기 유지율이나 결제 의향이 입증되었다고 판단하지 않는다. 실제 결제·환불, 다른 실제 기종, 서버 기반 저장은 검증 범위 밖이다.

## 최종 설치와 보존

최종 설치본은 **직접 플레이 0.11.1 (b37)**, `com.isolatedyouth.idlekingdomrpg.lobbyqa`다. Unity 6000.3.21f1 ARM64 IL2CPP 빌드 오류 0개, 경고 89개다. 전체 재컴파일 시 집계된 Google Play Games 구형 API·기존 미사용 코드·압축 앱 아이콘 등의 경고는 `Final/build-messages.txt`에 남겼다. 개발 APK는 1,333,090,100바이트다. 진단 define과 계정 강제 지정이 없다.

일반 타이틀 → 게스트 로그인 → 원래 계정의 방치 보상 → 전투·뽑기·장비·가방·가이드·프로필·던전·마탑·설정 진입을 확인했다. 원래 계정의 처치는 32,857 → 33,155로 증가했다. 기존 장비 300개와 개별 보관 100개, 수량형 보관·강화·잠금·장착·전직·마탑 스킬·성장을 보존했고 고대주화를 쓰지 않았다. `user-preservation.json`의 보존 조건은 모두 true이며 해당 앱 프로세스 런타임 오류는 0개다.

원본과 QA 종료 후 저장은 각각 `Original`, `PostQA`에 백업했다. 이번 원본에서 QA 저장 두 개와 설정만 복원했고 다른 계정 저장 46개가 변하지 않았음을 바이트 비교했다. 진단 파일 927개를 제거했으며 최종 앱의 진단 파일은 0개다. 기기 기본 사용자 프로필에 이 프로젝트 앱은 최신 한 개만 남았다. 앱은 원래 계정의 메인 전투 화면에서 바로 플레이할 수 있다.

기기 표시 비율 검사는 동일한 Samsung 기기의 해상도 변경이며 여러 기기 검사가 아니다. 검사 후 기존 1080×2316, density 450으로 되돌렸다. 사용자 저장 원문·기기별 설정·APK는 버전 관리하지 않고 요약 검사와 캡처만 커밋한다.
