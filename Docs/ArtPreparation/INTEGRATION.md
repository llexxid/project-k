# 후속 연결 안내

## 현재 상태

현재 로스터, 씬, 스포너, 전투 규칙, 배경 선택 기능은 기존 상태입니다. 준비 프리팹을 채택할 때 필요한 연결만 아래에 남깁니다. 이 문서는 실행 중인 시스템이나 자동화 스크립트가 아닙니다.

## 몬스터

1. [카탈로그](MONSTERS.md)에서 채택할 프리팹과 원본 결손을 확인합니다.
2. 기존 몬스터 이름/ID·능력치 데이터·Addressables 생성 절차에 해당 프리팹을 등록합니다. 현재 2·3스테이지의 TinyRPG 등록을 교체하는 일은 이 시점에 진행합니다.
3. 기존 `Monster.OnAlloc`과 스탯 초기화 경로를 사용합니다. 에디터에서 프리팹을 단독 활성화하는 것으로 전투 초기화가 완료되는 것은 아닙니다.
4. 기본 상태 `Idle`, `Walk`, `Attack`, `Hurt`, `Dead`는 연결되어 있습니다. 추가 공격, 변신, 작업, 토템 소환은 준비 클립을 선택해 연결합니다. 범위·발사 시점·피해 판정은 별도 검증이 필요합니다.
5. 원본 결손이 있는 LootGoblin/Bat/Frog/OrcKid/미믹은 용도에 맞는 행동을 확정합니다. 정지 자세 대체를 실제 공격·사망 아트로 오해하지 마세요.
6. [크기 검수](MONSTER_SIZES.md)의 저장된 Visual 배율을 사용합니다. 새 몬스터는 발 위치와 몸체 중심을 루트에 맞췄습니다. 현재 HP바가 사용하는 `Renderer.bounds`에는 투명 여백·공격 이펙트가 포함되므로, 후속 HP바/데미지 표시 연결에서 `monster-sizes.json`의 몸체 높이와 원점을 기준으로 검수합니다. 기존 기본 Lancer 스프라이트를 기준으로 배율을 다시 확대하면 현재 병과보다 과도하게 커집니다.

## 효과·투사체

`VFX/Prepared`와 환경 Ambient 폴더의 프리팹은 SpriteRenderer + Animator로 구성됩니다. 이동·피해·풀링 스크립트는 추가하지 않았습니다. 기존 효과 생성 시스템에 넣을 때 소유자, 방향, 크기, 재활성화 시 재생 시작, 종료/반환 책임을 연결합니다. 단발 효과는 마지막 null 스프라이트로 숨기지만 오브젝트를 자동 삭제하지 않습니다. 정적 투사체와 반복 Flight/Spin은 해제될 때까지 표시됩니다.

## 환경

- 단계, 보스 여부, 던전 유형으로 5개 풀 중 하나를 고르고 같은 모드의 프리팹 중 하나를 선택하는 기능을 후속으로 구현합니다.
- 프리팹은 월드 원점·1단위 격자·32 PPU를 기준으로 만들었습니다. 전체 배경 범위는 32×48 world units입니다.
- 장식물은 중앙 `[-2.75,2.75] × [-7,7]`(보스 x ±3)에 들어오지 않습니다. 왕국군의 실제 공격 범위, 카메라 이동, HUD와 세이프 영역을 통합 시 다시 확인합니다.
- Scenery Tilemap 전체를 숨기면 장식이 줄어듭니다. 현재 저사양 모드에는 이 제어를 연결하지 않았습니다.
- Wasteland의 흔들리는 나무·균열·기포는 선택 가능한 별도 Ambient 프리팹입니다. 90개 기본 환경에는 상시 Animator가 없습니다.
- 31 PPU인 Legacy Forest와 32 PPU 준비 타일을 섞지 않습니다.

## 아틀라스와 기존 에디터 도구

준비 아틀라스는 `Include in Build=false`입니다. 채택한 콘텐츠만 기존 Addressables/빌드 정책에 맞게 포함합니다. 두 방식에 중복으로 넣어 텍스처를 이중 배포하지 않도록 확인합니다.

현재 `Atlas_Characters`는 [atlas-inputs.json](Manifests/atlas-inputs.json)의 첫 항목에 있는 기존 12개 텍스처를 직접 참조합니다. `Atlas_Equipment`는 이동한 폴더 GUID를 그대로 참조합니다. 현재 저장된 아틀라스는 정상입니다.

스크립트 수정 제외 요청 때문에 다음 기존 에디터 도구는 변경하지 않았습니다. **기존 생성 메뉴를 다시 실행하기 전, 아래 입력 경로/수집 정책을 갱신해야 합니다.**

| 파일 | 후속 변경 |
|---|---|
| `Assets/_Project/Scripts/Editor/Optimization/OptAtlases.cs` | 이전 `Scripts/Player/Job`, `Prefabs/Royal_Guard_Lancer`, EliteArcher 루트 대신 현재 사용 중인 12개 원본 텍스처 목록을 수집. RoyalGuard 전체를 넣으면 아직 쓰지 않는 변형까지 빌드에 포함되므로 피할 것 |
| 같은 파일의 장비 입력 | `Assets/_Project/Art/Sprites/Equipment/SourceSheets` |
| `Assets/_Project/Scripts/Editor/Optimization/OptTextureImport.cs` | 옛 Sprite 루트 제거, 현재 Art/Environment 경로 포함. 아틀라스 입력 텍스처에 중복 손실 압축을 적용하지 않도록 분류 |

Job/SO 등 게임 데이터는 코드의 경로 참조가 있는 기존 위치를 유지했습니다. `Assets/UGUI`와 별도 기능 모듈, 외부 SDK·플러그인의 구조도 유지했습니다. 이 작업에서 기존 `.cs` 파일은 바뀌지 않았습니다.

## 실제 기기 검증 전 확인할 기존 문제

- Android 빌드의 기존 사용자 서명 설정이 `Can not sign the application`에서 실패했습니다. Unity의 Keystore/Key Alias 인증을 사용자가 기존 환경에서 복구한 뒤 검증 빌드를 다시 만들 수 있습니다. 자격 증명이나 서명 정책을 변경하지 않았습니다.
- 개발용 게스트 계정은 서버 함수 시간 초과와 진행 데이터 마이그레이션 미완료로 전투 시작이 보류됐습니다. 데이터 마이그레이션 정책이나 서버를 변경하지 않았습니다.
- 기존 최적화 도구의 일부 UI 아틀라스는 압축된 외부 원본을 다시 패킹하며 경고를 냅니다. 외부 보관소를 수정하지 않고 처리할 별도 작업이 필요합니다.
