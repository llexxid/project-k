# 전투·성장·진행 개정 작업 기록

진행 중인 작업이다. 완료·기기 검증을 뜻하지 않는다. 시작 기준은 `3cd728cca`(0.12.1 b43), 작업 트리는 깨끗했다.

## 사용자와 확정한 방향

- 3장 이후 산적 → 고블린 → 오크 지역을 순환하며 스테이지 번호와 난도를 계속 올린다.
- 마탑은 왕국군 공격력 일부를 반영해 강화 상한 이후에도 성장한다.
- 장비 분해·자동 분해·필터·정렬 및 강화 전용 재화를 추가한다. 현재 기기의 사용자 장비함은 백업 후 비운다.
- 루비는 영구 성장 중심이며 육성 메뉴에서 골드와 별도 탭을 사용한다.
- 환생은 골드와 일시 골드 강화를 초기화하는 전통적 구조로 변경한다. 영구 보상 방식은 문답 진행 중이다. 아직 저장 초기화나 환생 정책 변경은 적용하지 않았다.

## 작업 묶음과 검증 상태

1. 전투 판정·표시: 강철의 의지, 흰색 보호막 바, 힘의 파동, 시체 충돌, 얼음 송곳, 성역·암석 봉인, 유성우, 마탑 공격력 반영. Unity 6000.3.21f1 컴파일·에셋 생성·레이어 참조 검증 통과. 0.13.0 b44 Android 빌드 성공(오류 0). SM-N986N에서 일반 적/보스 각 10개 제어 검사 통과. 강철의 의지 HP 99.18%에서 보호막 8,253 발생, 검을 들어 올리는 모션 및 HUD 흰색 보호막 직접 확인. 전체 VFX·경제·다양한 화면 비율 검증은 이후 묶음에서 계속한다.
2. 무한 지역 순환·던전 복귀·보스 자동 도전 UI: b47에서 Unity/Android 기능 검증 통과. 다른 화면 비율·체크박스 배경 대비는 후속 UI 묶음에서 보완.
3. 장비 경제·보관함·재화 드롭다운: 대기.
4. 구매 VFX 전수 후보 조사·Comfy 개선·환경 변주: 후보 조사 중.
5. 루비·환생 설계 확정, 메뉴·성장 연결: 문답 진행 중.
6. 원본 기획서·카탈로그 개정, Unity/Android 종합 검증·실계정 복원·최종 설치: 대기.

## 원인과 수정 의도

- 기획서가 3장 이후 콘텐츠를 막고 있어 런타임도 3-11에서 자동 도전을 끄고 3-10으로 강제 복귀했다.
- 마탑 기존 피해는 고정 기초값에 강화·각성만 곱했다. 새 후보식은 기존 피해 + 왕국군 공격력 합계 × (스킬 기본값 / 400) × (1 + 강화×0.005 + 각성×0.025). 기존 강화 가치를 보존하고 다중 타격의 합산 비중을 고려했다. 실제 전투 기여도 검증 전 수치다.
- 힘의 파동은 속도 2에 감쇠 10을 적용해 총 밀침이 약 0.2 units에 그쳤다. 시전 모션 0.2초 뒤 낮은 피해(공격력 35%), 약 1 unit 밀침과 1초 기절을 적용하도록 조정했다. 보스 제어 면역은 기존 규칙을 유지한다.
- 사망 시 밀침 속도를 끊고 콜라이더·물리 시뮬레이션을 종료한 뒤 사망 이벤트를 보낸다. 풀 재사용 때 물리를 복구한다.
- 일부 UGUI 게이지는 sprite=null인 Filled Image여서 fillAmount가 무시될 수 있었다. 직사각형 공용 스프라이트를 연결하고 체력·보호막을 같은 비율로 표시한다.
- 유성우 6→18발, 발당 기초값 62→28. 기본 총량 372→504로 증가하며 3배 피해 폭증은 피한다.

## 장비와 성장 메뉴 검증 b49 및 b50

- 장비 분해 전용 재화 EquipmentStone=7을 추가했다. 일반/레어/에픽 기본 분해량은 1/4/12이며 강화에는 `2 × 등급 기본 분해량 × (1 + floor(현재 강화 / 3))`개를 쓴다. 기존 강화 효과·상한·성공률 100%는 유지한다. 강화 무기 분해에는 실제 지출한 강화석의 80%를 내림해 돌려준다.
