# 전투·성장·진행 개정 작업 기록

진행 중인 작업이다. 완료·기기 검증을 뜻하지 않는다. 시작 기준은 `3cd728cca`(0.12.1 b43), 작업 트리는 깨끗했다.

## 사용자와 확정한 방향

- 3장 이후 산적 → 고블린 → 오크 지역을 순환하며 스테이지 번호와 난도를 계속 올린다.
- 마탑은 왕국군 공격력 일부를 반영해 강화 상한 이후에도 성장한다.
- 장비 분해·자동 분해·필터·정렬 및 강화 전용 재화를 추가한다. 현재 기기의 사용자 장비함은 백업 후 비운다.
- 루비는 영구 성장 중심이며 육성 메뉴에서 골드와 별도 탭을 사용한다.
- 환생은 골드와 일시 골드 강화를 초기화하는 전통적 구조로 변경한다. 영구 보상 방식은 문답 진행 중이다. 아직 저장 초기화나 환생 정책 변경은 적용하지 않았다.

1. 전투 판정·표시: 강철의 의지, 흰색 보호막 바, 힘의 파동, 시체 충돌, 얼음 송곳, 성역·암석 봉인, 유성우, 마탑 공격력 반영. Unity 6000.3.21f1 컴파일·에셋 생성·레이어 참조 검증 통과. 0.13.0 b44 Android 빌드 성공(오류 0). SM-N986N에서 일반 적/보스 각 10개 제어 검사 통과. 강철의 의지 HP 99.18%에서 보호막 8,253 발생, 검을 들어 올리는 모션 및 HUD 흰색 보호막 직접 확인. 전체 VFX·경제·다양한 화면 비율 검증은 이후 묶음에서 계속한다.
2. 무한 지역 순환·던전 복귀·보스 자동 도전 UI: 대기.
3. 장비 경제·보관함·재화 드롭다운: 대기.
4. 구매 VFX 전수 후보 조사·Comfy 개선·환경 변주: 후보 조사 중.

## 원인과 수정 의도

- 기획서가 3장 이후 콘텐츠를 막고 있어 런타임도 3-11에서 자동 도전을 끄고 3-10으로 강제 복귀했다.
- 마탑 기존 피해는 고정 기초값에 강화·각성만 곱했다. 새 후보식은 기존 피해 + 왕국군 공격력 합계 × (스킬 기본값 / 400) × (1 + 강화×0.005 + 각성×0.025). 기존 강화 가치를 보존하고 다중 타격의 합산 비중을 고려했다. 실제 전투 기여도 검증 전 수치다.
- 힘의 파동은 속도 2에 감쇠 10을 적용해 총 밀침이 약 0.2 units에 그쳤다. 시전 모션 0.2초 뒤 낮은 피해(공격력 35%), 약 1 unit 밀침과 1초 기절을 적용하도록 조정했다. 보스 제어 면역은 기존 규칙을 유지한다.
- 사망 시 밀침 속도를 끊고 콜라이더·물리 시뮬레이션을 종료한 뒤 사망 이벤트를 보낸다. 풀 재사용 때 물리를 복구한다.
- 일부 UGUI 게이지는 sprite=null인 Filled Image여서 fillAmount가 무시될 수 있었다. 직사각형 공용 스프라이트를 연결하고 체력·보호막을 같은 비율로 표시한다.
- 유성우 6→18발, 발당 기초값 62→28. 기본 총량 372→504로 증가하며 3배 피해 폭증은 피한다.

## 조사 출처와 적용 판단

- [Kongregate / The Math of Idle Games, Part I](https://www.kongregate.com/en/pages/the-math-of-idle-games-part-i): 생산·비용·영구 보상의 곡선을 함께 비교해야 한다. 이 게임에서는 처치 시간과 수입을 분리하고 환생 직후 재진행 시간을 계산한다.
- [Pichlmair & Johansen / Designing Game Feel. A Survey](https://arxiv.org/html/2011.09201v1): 본문 IV-A~C의 물리 동작·피드백·입력 지원 구분을 검토했다. 타격과 소리·입자의 시간 일치, 읽을 수 있는 밀침·트윈에 적용한다.
- [Daeun Hwang / Player Engagement with Idle Games](https://escholarship.org/uc/item/0b07v51w): 2025년 석사 논문. 6장 설계 시사점과 7장 한계까지 검토했다. 부재 중 진행, 눈에 보이는 기능 해금·성장, 그래픽 피드백을 참고하되 소규모 집단 인터뷰(5명)와 제한된 게임·관찰기간의 결과를 보편적 정답으로 보지 않는다.
- Riot VFX 가이드의 예전 공식 PDF URL은 현재 홈페이지로 리다이렉트된다. 문서를 읽은 것으로 기록하지 않고 대체 공식 출처를 찾는 중이다.
- [AFK Journey 공식 게임 소개](https://www.youtube.com/watch?v=-gvaOFRoPFk): 실제 재생 화면 5:08 전투, 5:17 회복과 자막 확인. 발밑의 작은 지면 링, 몸을 가리지 않는 회복 표시, 화면 가장자리의 숲·바위 배치를 참고한다. 전체 영상 시청을 뜻하지 않는다.
- [Riot VFX Art Education](https://www.riotgames.com/en/artedu/visual-effects), [VALORANT Shaders and Gameplay Clarity](https://www.riotgames.com/en/news/valorant-shaders-and-gameplay-clarity): 읽기 쉬운 효과와 성능 예산을 우선한다. 장판과 순간 타격의 명도·지속시간을 분리하고 저사양에서도 판정 정보를 보존한다.

## 추가 전투 감사 (사용자 2026-09-20 지적)

- CombatMotion이 발 기준이라고 설명하면서 실제로는 서로 다른 pivot의 transform 위치를 비교했다. 발 위치로 접근/근접 판정을 맞추고, 이동하는 쪽이 상대 발 공간 앞에서 멈추도록 수정했다. 상대 진영의 접근 이동으로 왕국군을 미는 separation은 제거한다.
