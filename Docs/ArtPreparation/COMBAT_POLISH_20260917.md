## 검증 과정에서 구별한 문제

- 입장권 소진으로 상위 던전 검증이 거부된 것은 정상 게임 제한이었다. 진단 계정에만 입장 조건을 설정해 반복 검증하도록 시험 도구를 수정했다.
- USB 응답 지연 때문에 기절 잔여 시간이 1.7초보다 작다는 기존 시험이 실패했다. 실제 타격 시간+잔여 시간으로 만료를 검증하도록 바꿨으며, 게임의 기절 시간은 정확히 2초였다.
- 설정 메뉴가 탭으로 개편된 뒤 옛 시험이 숨겨진 컨트롤을 찾던 문제를 수정했다. 이제 실제 탭을 눌러 접근한다.
- 처음 b17 빌드 호출의 namespace를 잘못 지정해 실행 진입점을 찾지 못했다. 올바른 진입점으로 재실행했고 빌드가 성공했다.
- 새 계정 검사 후 루비 던전 해금 레벨이 초기화돼 입장이 거부됐다. 입장권만 복구하던 시험 도구에 기존 중반 진행 시험 데이터를 함께 적용했다. 일반 게임의 해금 제한은 변경하지 않았다.
- 새 검증 묶음이 마탑 결과의 `passed`를 숫자로 잘못 읽어 한 번 중단됐다. 실제 `passed=true, count=186` 응답을 확인해 시험 집계를 수정한 뒤 재실행했다.
