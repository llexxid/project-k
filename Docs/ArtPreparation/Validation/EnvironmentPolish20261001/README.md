# 2026-10-01 배경·라이트닝 검수

## 적용

배경 90개를 같은 ID로 재생성했다. 중앙 시야와 주변 소품의 간격을 우선하고, 작은 특징 군집·반대쪽 보조 군집·코너 나무로 구성했다. 기존 무작위 선택과 전투 로직은 변경하지 않았다. 라이트닝 기본 아이콘은 실제 `LightningOriginal` 0/1/2 프레임을 사용한다. 개화 아이콘과 VFX는 변경하지 않았다.

## 검증 범위

- Unity 6000.3.21f1에서 import, C# 컴파일, 90개 저장 프리팹 렌더 검증 통과.
- 기본 540×960 90장 및 각 지역 Main/Boss/Special 대표의 360×800, 432×1008, 720×960 45장, 총 135장.
- 실제 main 씬 Main Camera + CM_GamePlay의 perspective FOV60, 위치(0,0,-13)를 읽어 사용. 직교 크기5를 사용하는 모사 화면이 아니다.
- 중앙 Scenery 침범0, 소품 bounds 겹침0, 누락 참조0, 충돌체0. 90개의 렌더 픽셀 해시가 모두 다르다.
- Ground에 사용 가능한 25개 원본 타일의 알파가 모두255임을 검사. 기존 3개 TilemapRenderer 유지.
- 90장 번호별 연락판을 눈으로 확인했고, 숲 경계·연못·던전 바닥·황무지·긴 폰 보스형을 확대 검토했다.
- 브라우저 갤러리 번호 검색, 확대, 수정 전후 전환 확인. 배경01–90, 일반 라이트닝91.
- 실제 Android 검증은 `device-summary.json`에 별도 기록한다. 이 문서의 정적 렌더가 실제 전투/터치 검증을 대신하지 않는다.

## 발견과 재수정

1. 일반 소품이 배치 예약에서 제외되어 숲에서 bounds 중첩이 반복됐다. 모든 소품을 네이티브4픽셀 간격으로 예약한다.
2. 꽃밭 윗조각, 물 뒤 잔디색, 던전 가장자리 갈색 흙, 황무지 균열 조각 섞임을 제거하거나 연결했다.
3. 1차 렌더에서 황무지 고목·풀·두개골의 범위가 서로 다른 오브젝트를 포함함을 발견했다. 4개 범위 수정 후 전후 연락판으로 온전한 형태를 확인했다.
4. 작은 소품의 빈 여백 때문에 긴 화면 외곽에서 그림이 더 잘렸다. 28종의 투명 테두리만 잘랐으며 실제 RGBA 픽셀·PNG 해시·PPU32·피벗·GUID·spriteID·fileID를 보존했다. 홀수 폭도 보이는 왼쪽 경계를32PPU 격자에 맞춘다.
5. Forest 벽에 추가 끝조각이 필요하다는 초기 추정은 원본 확대 검토로 기각했다. 3,24 + 4,24가 온전한 조합이며 별도 벽을 시작하는5,24는 추가하지 않는다.

## 크기와 비용

새 배경 텍스처나 런타임 오브젝트를 만들지 않았다. 평균 GroundDetails/Scenery 셀 수는 다음과 같다. 줄어든 셀 수를 기기 FPS 향상 수치로 해석하지 않는다.

## 보존·제한

- 수정 전135장과 수정 후135장, 프리팹 검사 결과, 소품 범위/투명 여백 검증 JSON과 전후 연락판을 보존한다.
- HUD와 전투원을 제외한 배경 비교다. 긴 폰 보스형은 더 넓은 중앙 여백을 우선하므로 큰 수관은 화면 가장자리로 잘린다.
- 실제 성능 향상, 모든 실기기/모든 웨이브 플레이를 검증했다고 주장하지 않는다.

## Android 설치 확인

- 자연 프로필 검수 빌드 `배경 아이콘 검수 0.15.1 (b66)`를 생성했다. IL2CPP Android 빌드는 Succeeded, 오류0, 경고90이었다. 경고에는 기존 소셜 API 폐기 예정 안내와 런처 아이콘 압축 안내가 포함된다.
- 연결된 SM-N986N에 업데이트 설치했다. 설치 전후 기존 저장·환경설정59개의 해시가 일치했다. 최신 검수 앱을 기기에 유지했다.
- 타이틀과 버전을 확인했다. Google 로그인에서 저장된 계정2개 중 사용자의 기존 게임 계정을 확정할 수 없어 선택하지 않았다. 계정 선택 전에는 실제 전투 배경·일반 라이트닝 아이콘의 실기기 표시·성능을 검증한 것으로 취급하지 않는다.
- 계정명, 이메일, 인증정보와 원본 기기 기록은 문서·갤러리에 포함하지 않는다. 자세한 검증 범위는 `device-summary.json`에 기록한다.
