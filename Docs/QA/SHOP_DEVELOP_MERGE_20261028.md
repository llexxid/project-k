# 상점 패치 develop 통합 확인

사용자의 `demoLaunch-alpha` 상점 커밋 `66724e0e4`에서 상점 관련 변경만 `develop`에 이식했다. 기준은 기존 `develop`의 `5dbf048c9`이며 상점 복원 커밋은 `4c5a3865e`다.

- 햄버거 메뉴의 상점 팝업, 추천·주화/골드·매일 광고 3개 탭과 11개 상품을 연결했다.
- 상점 프리팹·메인 메뉴 버튼·카탈로그 참조와 기존 생성 경로를 함께 반영했다. 구매·교환·일일 광고 상품은 원래 요청대로 미리보기이며 재화나 서버 상태를 변경하지 않는다.
- 기존 서버·인증·지갑·오프라인 보상·출석·우편·플러그인·패키지·프로젝트 설정은 작업 전 develop과 동일하다. 메인 프리팹은 기존 오브젝트를 삭제하지 않고 상점 버튼만 추가했다.
- 과거 패치의 6시간 보상·오프라인 광고 임시 버튼은 기존 구현을 우선해 제외했다. 현재 최대 8시간을 유지한다.
- 잘못 시도한 다른 팀원의 `feat/advertisement` 병합은 원격 푸시 전에 로컬 이력에서 제거했다. 해당 광고 SDK·보상 코드 및 커밋은 최종 develop에 포함하지 않는다. 빌드가 바꾼 설정과 생성 파일도 복구했다.
- 사용자 최종 지시에 따라 추가 빌드·기기 테스트는 하지 않는다. 최종 확인은 Git 이력·파일 비교·직렬화 참조 연결을 기준으로 한다.
