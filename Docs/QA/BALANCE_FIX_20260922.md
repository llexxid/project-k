# 보상·환생 및 화면 갱신 수정

대상: `ui-polishing`, **0.14.2 (b63)**. 2026-09-22 신규 유저 플레이 보고서에서 재현한 문제 중 범위가 작은 오류와 추가 요청을 수정했다. 최신 APK 설치와 기존 저장 데이터 복원을 완료했다.

## 연결된 Android 확인

Samsung SM-N986N, Android 13 한 대에서 실제 터치로 확인했다. 기존 1080×2316 화면 설정을 유지했다. 원본 저장 데이터를 먼저 백업한 후 재현용 데이터로 검사했으며, 이번 검사를 신규 유저의 자연 진행으로 간주하지 않는다.

핵심 회귀 검사는 b61에서, 최초 보상·수량 표시 및 최종 로그인 확인은 b63에서 수행했다. b63에서도 Unity 검사 전체가 다시 통과했다. IL2CPP 빌드는 오류 0, 경고 22로 성공했다. 검사 구간의 앱 로그에서 NullReference·MissingReference·IndexOutOfRange·ArgumentException 및 치명적 종료는 관찰되지 않았다. 빌드 경고 전체를 해소한 작업은 아니다.

원본 백업의 파일 **66개를 SHA-256으로 대조해 복원**했다. 복원 후 기존 공격력 Lv.130·체력 Lv.93·환생 성장 30과 원래 전직 상태로 정상 진입했다. 확인 과정의 정상 오프라인 보상과 전투 수익은 발생했다. 테스트 데이터와 진단용 파일은 앱 데이터 복원 과정에서 정리했고, 앱은 종료해 두었다.

## 범위

퀘스트 가독성·튜토리얼 로직은 변경하지 않았다. 스테이지 변경은 활 최초 보상 한 셀과 환생 시 자동 도전을 끄던 호출 제거로 제한했다. 카탈로그의 나머지 ZIP 항목은 바이트 단위로 보존했으며 생성 데이터 차이도 보상 직업과 카탈로그 해시뿐이다. 왕국군 및 마탑 파일의 기존 튜토리얼 연결 코드는 유지했다.

공유 게스트 계정 인증 구조, 초반 장비 운에 따른 성장 편차, 장기 환생 보상 곡선, 메뉴 체류 시간의 퀘스트 집계 정책은 이번 소규모 수정 범위에 포함하지 않았다. 기존 오프라인 보상은 최고 사냥 기록을 기준으로 하는 정책을 유지한다. 수동 시전 안내와 튜토리얼 자동 진입 역시 별도 UX 검토 대상으로 남긴다.

전투 공식·가차 등급 확률·환생 보상 곡선·스프라이트와 렌더링 설정은 변경하지 않았다. 여러 기기·다른 화면 비율·장시간 성능 비교 및 자연 진행으로 3회 환생하는 전체 여정은 이번 수정 후 다시 실행하지 않았다. 관련 기존 플레이 결과는 [신규 유저 보고서](ANDROID_NEW_PLAYER_20260922.md)를 참조한다. 원본 계정 백업과 상세 로그는 개인정보가 포함될 수 있어 Git에 넣지 않고 `Recordings/BalanceFix20260922`에 보존했다.
