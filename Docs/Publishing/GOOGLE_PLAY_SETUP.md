# 왕국군 키우기 Google Play 등록 작업표

작성일: 2026-09-24. 범위: 첨부된 `Finish setting up your game`의 11개 항목.

현재 확정 사항: 대한민국 우선 출시, 루도스(Ludos), 최초 출시본에 광고·Google Play 인앱결제 포함. 광고 업체는 미정.
기준 소스: 현재 `develop` 작업 폴더, 운영 기획서, 2026-09-24 콘솔 읽기 전용 조회.

**계정 유형 정정:** 사용자는 조직 계정이라고 알려주었으나, 로그인된 콘솔에는 `Personal account`로 표시된다. 실제 앱 대시보드에도 **12명 이상이 14일 연속 참여하는 비공개 테스트 후 프로덕션 액세스 신청**이 요구된다. 현재 참여자는 0명, 프로덕션은 비활성이다. 내부 테스트는 이 비공개 테스트를 대체하지 않는다. 계정 전환·테스트 시작·설정 변경은 수행하지 않았다. [공식 테스트 요구사항](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)

콘솔 현재 앱 이름은 `IdleKingdomRPG`, 패키지는 `com.isolatedyouth.idlekingdomrpg`이며 Draft 상태다. 공개 스토어 이름으로 아래 한국어 제목을 준비했다. 미심사 내부 테스트의 임시 이름 표시는 별도 현상이다.

이 문서는 등록 작업 자료다. 프로젝트 행동 규칙은 [AGENTS.md](../../AGENTS.md)에 있다.

## 3. 콘텐츠 등급 설문 근거표

설문 첫 단계의 담당 이메일은 `kingdomidle@ludosinteractive.com`을 사용한다. 카테고리는 게임이다.
문항은 국가·이전 답변에 따라 달라질 수 있으므로 아래를 그대로 모든 질문에 일괄 대입하지 않는다.

| 질문 주제 | 답변 방향 | 근거·남은 확인 |
|---|---|---|
| 폭력 묘사 | 예 | 칼·창·마법으로 적을 공격하는 전투가 있음 |
| 인간형 대상 | 인간형도 포함하여 확인 | 산적처럼 인간을 표현하는 적이 있으므로 '비인간만'으로 단정하지 않음 |
| 표현 방식 | 도트 그래픽의 판타지 전투 | '사실적/비사실적', 빈도 등 세부 질문은 실제 연출과 대조 |
| 피·유혈·신체 훼손 | 미확정 | 모든 등장 적·사망 애니메이션·효과를 실제 화면에서 확인해야 함 |
| 인앱 구매 | 예 | 사용자 확정 출시 계획 |
| 무작위 아이템의 유료 획득 | 유료 재화·상품이 뽑기와 연결되면 예 | 장비·마탑 뽑기가 존재. 무료 보상만 있다는 전제 금지 |
| 도박·모의 도박 | 뽑기와 구별해 문항별 판단 | 슬롯·룰렛 등 카지노 기능, 현금화·현물 보상 여부 확인 |

| 이용자 공개 콘텐츠 | 공개 닉네임·프로필·게시물 등 확인 후 답변 | 사용자 입력이 다른 사람에게 노출되는지까지 확인 |
| 성적 표현·언어·약물·공포 | 최종 콘텐츠 확인 후 답변 | 코드 검색만으로 '없음' 확정 금지 |

전체이용가·12세·15세 등 결과 등급은 설문 산출값을 기록한다. 희망 등급에 맞춰 사실을 바꾸지 않는다.

## 4. 대상 연령 선정: 만 13세 이상

사용자가 기획·구현에 따른 결정을 위임했다. 최초 출시의 대상은 **만 13세 이상 청소년·성인**, 콘솔 선택은 **13–15세 / 16–17세 / 18세 이상**으로 정한다. 5세 이하·6–8세·9–12세는 최초 대상에 넣지 않는다. 이는 운영·마케팅 대상의 선정이며 IARC 결과 등급을 미리 정하는 조치가 아니다.

선정 근거:

- [운영 기획 데이터](../../AI/planning/beta-20260913/정리본/왕국군_키우기_기획데이터.txt)의 핵심은 세 병사의 역할 편성, 장비 투자와 재화 배분, 다음 도전 시점 선택이다. 유아용 조작·학습이나 저연령층 중심의 콘텐츠로 설계된 근거는 확인하지 못했다.
- [현재 마탑 구현](../../Assets/MageTower/README.md)은 장착·강화·각성·개화·수동 시전을, [환생 검증](../QA/BALANCE_FIX_20260922.md)은 초기화와 영구 성장의 구분을 요구한다. 이 판단 구조를 이해하며 장기 성장에 관심이 있는 청소년·성인을 기본 고객으로 잡는 것이 적절하다.
- 자동 전투와 도트 그림만으로 '모든 연령 대상'이라고 판단하지 않았다. 광고·과금 존재만으로 성인용이라고 판단하지도 않았다. 기획서에 최소 연령이 명시된 것은 아니므로 이 숫자는 위 근거에서 도출한 출시 권고다.
- 9–12세를 실제 마케팅 대상으로 추가하거나 최종 콘텐츠가 변경되면 대상 선언도 다시 검토한다. 최종 등급이 이 대상과 충돌하면 콘텐츠 또는 실제 서비스 대상을 조정한다.

**만 13세는 국내 만 14세 미만에 해당한다.** 동의를 근거로 해당 아동의 개인정보를 처리하는 경우 법정대리인 동의·확인이 필요하다. `13–15세`를 골랐다고 이 절차가 면제되지 않는다. 현재 로그인 전 연령 확인·법정대리인 동의 구현은 검증되지 않았다. [개인정보 보호법 제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398523)

Google도 13–15세가 지역에 따라 아동을 포함한다고 설명한다. 아동이 포함된 혼합 대상 서비스로 준비하고 광고 업체 선정 시 아동·연령 미확인 이용자 처리, 자체 인증 광고 SDK와 버전, 개인정보 전송 제한을 확인한다. 연령 확인 전에 광고 SDK부터 초기화하지 않도록 데이터 흐름을 검토한다. Google 로그인·PlayFab도 아동 이용 조건을 별도 확인한다. 현재 공용 개발용 게스트 계정은 아동용 대체 로그인으로 인정할 수 없다. [대상 연령 지침](https://support.google.com/googleplay/android-developer/answer/9867159?hl=ko), [Families 정책](https://support.google.com/googleplay/android-developer/answer/9893335?hl=en)

## 6. 작업 순서

1. 등록 담당자가 이 문서의 확정 입력값과 스토어 소개문을 검토하여 입력한다. 이번 작업에서는 콘솔 입력·저장을 수행하지 않는다.
2. 공개용 업무 연락처와 대상 연령을 반영한다.
3. 콘텐츠 등급 설문의 실제 질문에 따라 근거표를 대조한다.
4. 개인정보 문서의 미확정 칸을 채우고 공개 웹페이지에 게시한다.
5. 앱 액세스 안내의 미확정 경로를 실제 출시본에서 검증한다.
6. 최종 데이터 흐름을 확정하고 데이터 보안 양식을 작성한다.
7. 스토어 그래픽·실제 스크린샷을 등록한다.
8. 11개 항목의 실제 저장 상태와 '게시 개요'를 확인한다. 문서만 작성한 항목을 완료로 기록하지 않는다.
9. 현재 계정에 표시된 비공개 테스트를 진행하고 실제 피드백·수정·재검증 기록을 모아 프로덕션 액세스를 신청한다. 기간 경과만으로 자동 출시되지 않는다.

계정 삭제 기능과 광고·결제 기능의 구현 완료 여부를 문서로 대신할 수는 없다. 아직 미구현인 사항에 대해 '가능', '제공', '검증 완료'로 제출하지 않는다.

## 7. 작업 기록

- 2026-09-24: 기존 Git 변경 없음 확인. 등록 문서 묶음 신규 작성.
- 사용자가 직접 로그인한 뒤 계정 홈과 앱 대시보드만 읽기 전용 조회. 입력·저장·심사 제출·서버 변경은 수행하지 않음.
- 현재도 정부·금융·건강 3/11 완료 표시. 각 완료 항목의 저장된 세부 답변까지 조회한 것은 아님.
- 실제 개인 계정 표시와 비공개 테스트 12명/14일 요건, 참여자 0명 확인.
- 게임 코드·프리팹·SDK·버전·빌드 설정은 이 문서 작업에서 변경하지 않음.
- 등록 항목 11개와 모든 문서 내부 파일 링크 확인. 스토어 이름 7자·간단 설명 40자·자세한 설명 744자로 입력 한도 이내임을 확인.
- 공개 초안에서 개인 휴대전화·인증정보 미기재 확인. 문서만 변경했으므로 Unity·Android 빌드를 새로 수행하지 않았고, 실제 심사 로그인·삭제·광고 연동 검증은 남아 있음.
