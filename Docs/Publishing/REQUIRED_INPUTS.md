# 제공해 주실 자료 — 출시·사이트 공개용

2026-09-27. 가능한 정보는 서류에서 추출해 작성한다. **비밀번호·인증 코드·서버 비밀키는 보내지 않는다.** 서류의 주민등록번호·개인 계좌·불필요한 개인정보는 가린다. 원본 서류는 공개 사이트나 Git에 넣지 않고 확인된 공개 표시사항만 반영한다.

## 1. 먼저 받을 서류

| 우선순위 | 자료 | 여기서 확인할 내용 |
| --- | --- | --- |
| **필수** | **사업자등록증** | 정확한 법적 상호, 대표자 성명, 사업자등록번호, 사업장 주소·업종. 브랜드 Ludos Interactive와 법적 상호를 구별 |
| 보유한 경우 | 통신판매업 신고증 | 신고번호·신고 상태. 미신고라면 ‘미신고’라고 알려주면 적용·면제 여부 검토 |
| 보유한 경우 | 게임제작업·게임배급업 등록증 | 등록 주체·등록번호. 미등록은 그렇게 알려주면 됨 |
| 법인인 경우에만 | 법인등기사항증명서의 상호·대표·본점 관련 부분 | 사업자등록증과 일치하면 중복 서류는 생략 가능. 주민번호가 있는 부분은 가림 |

통신판매업·게임업 등록증은 모든 데모 상황에서 무조건 이미 있어야 한다는 뜻이 아니다. 현재 등록 여부와 사업 형태·제공 방식을 먼저 확인한다. 사업자등록증부터 주면 나머지 중 실제 필요한 것만 좁힐 수 있다.

## 2. 서류로 알 수 없는 필수 확인

| 답변자 | 필요한 내용 | 짧은 답변 예시 |
| --- | --- | --- |
| 대표자 | 공개 업무용 전화번호, 공개 가능한 사업장 주소가 등록 주소와 같은지 | ‘업무용 번호 준비 중 / 주소 동일’. 개인 번호 공개가 싫으면 업무용 번호 마련 |
| 대표자 | 지원 이메일 실제 수신 가능 여부, 개인정보·삭제 요청 처리 책임자 | ‘메일 수신 확인 / 대표자가 담당’. 담당자 실명은 등록증과 대조 |
| 서버 담당자 | 실제 로그인으로 전달받는 항목, 진행 데이터 저장 여부, 이용 중인 업체·서비스 및 저장/접근 국가 | 구성표 또는 SDK/서비스 목록. 비밀키 제외 |
| 서버 담당자 | 보유기간·백업 주기/삭제 시점, 로그 보존, 계정 삭제 API와 실제 삭제 시험 결과 | 현재 구현 상태와 아직 없는 기능을 구별 |
| 대표자+개발 담당 | 13세 이용자의 법정대리인 동의·확인 및 동의 전 처리 제한 방식, 동의 기록 관리 | 제안된 이메일 동의 방식의 운영 가능 여부와 앱 연동 담당 |
| 대표자 | Play 계정 유형 확인 | 앞선 조회에는 Personal로 표시되어 조직 계정이라는 답변과 불일치. 조직 변경 여부 또는 현재 화면의 유형 |

현재 로그인 화면의 ‘로그인하면 약관·방침 동의 간주’ 문구와 링크·동의 흐름도 수정·검증해야 한다. 문서 링크만 게시해서 해결되는 부분은 아니다. 서버 관리와 콘솔 수정은 이번 작업에서 하지 않았다.

## 3. 지금 없어도 되는 정보 / 뒤에 필요한 정보

- **사이트 배포 때:** 회사 소유 Cloudflare 계정으로 사용자가 직접 로그인. 초기에는 무료 pages.dev 주소를 사용하므로 도메인 구매 불필요. 계정 비밀번호를 채팅에 보낼 필요 없음.
- **선택:** `ludosinteractive.com` 소유/DNS 관리 권한과 연결 희망 주소. 초기 무료 제공 주소로도 시작 가능.
- **선택:** 별도 회사 소개 문구, 회사 로고, 홍보 영상, SNS. 없으면 이번에 만든 기본 구성을 사용.
- **실제 광고 도입 전 필수:** 광고사·중개 SDK 전체 목록, 아동/연령 처리 설정, 수집·국외 이전 항목, 판매자 ID와 app-ads.txt 정보. UI-only 데모 단계에서는 미정 상태를 사실대로 유지.
- **실제 결제 도입 전 필수:** Play 상품 ID·현지 가격·지급/환불/광고제거 복원 정책, 결제/소비/서버 검증 담당. 인증키는 공유하지 않음.
- **공개 직전:** 최종 AAB와 실제 데이터 처리·확률 대조 결과, 시행일, 공개 주소. 서류만으로 채울 수 없는 실행 검증이다.
