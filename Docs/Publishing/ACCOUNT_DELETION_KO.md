# 왕국군 키우기 계정 삭제 안내

검토일: **2026-09-27**. 상태: **게시 전 검토**. 초기 운영은 이메일 접수와 운영자 처리 방식으로 설계한다. 별도 로그인 웹앱 없이도 시작할 수 있지만 실제 삭제 능력과 앱 안 요청 경로를 확인해야 한다. Google 정책상 이메일 경로를 둘 수 있다는 것이 기능 미구현을 허용한다는 뜻은 아니다.

## 계정과 데이터 삭제 요청

Ludos Interactive의 「왕국군 키우기」 게임 계정과 관련 데이터의 삭제를 요청할 수 있습니다. Google 계정 자체를 삭제하는 요청은 아니며, 앱을 제거한 뒤에도 이메일로 요청할 수 있습니다.

### 이메일로 요청하기

**kingdomidle@ludosinteractive.com**으로 다음 내용을 보내 주세요.

- 제목: `[왕국군 키우기] 계정 삭제 요청`
- 삭제를 요청한다는 의사
- 게임 계정 ID를 알고 있다면 해당 ID, 모르면 “계정 ID 모름”
- 이용한 로그인 방식과 회신 가능한 이메일 주소

계정 ID를 모르거나 앱에 들어갈 수 없다면 그 사정을 알려 주세요. 앱을 다시 설치하도록 요구하지 않고, 회사가 실제 보유한 계정 정보와 연결할 수 있는 최소한의 확인 방법을 안내합니다. 닉네임만으로 삭제를 승인하지 않습니다.

**비밀번호, 일회용 인증 코드, 전체 카드번호, 신분증 전체 사본은 보내지 마세요.** 다른 사람의 계정이 삭제되지 않도록 필요한 범위에서 소유 여부를 확인합니다. 법정대리인·대리인의 요청은 해당 계정과 대리 권한 확인 방법을 별도로 안내합니다.

### 삭제 범위

삭제 대상으로 확인된 게임 계정의 식별·로그인 연결 정보, 프로필, 회사가 관리하는 진행도·재화·장비·스킬·퀘스트 내역을 삭제합니다. 회사가 처리업체에 맡긴 관련 게임 데이터도 삭제·결과 확인 범위에 포함합니다.

계정 삭제 후 해당 진행도와 계정에 연결된 보유 내역은 다시 이용할 수 없게 됩니다. 단순 로그아웃이나 로컬 진행 초기화로 계정 삭제를 대신하지 않습니다. 기기에만 남아 회사가 원격으로 삭제할 수 없는 자료는 해당 사실과 정리 방법을 안내합니다.

### 별도로 보존하는 정보

법률상 보존 의무가 적용되는 실제 거래기록만 일반 게임 데이터와 구분해 보관합니다.

| 기록 | 보존기간 | 범위 |
|---|---|---|
| 계약·청약철회 | 5년 | 해당 거래 식별자와 계약·철회 내역 |
| 결제·공급 | 5년 | 주문·상품·금액·지급·취소·환급 확인 내역 |

현재 준비하는 데모의 결제 화면은 실제 결제를 처리하지 않습니다. 존재하지 않는 구매 기록을 위 기간 동안 보관한다는 의미는 아닙니다. 기록별 근거와 다른 보유 기준은 [개인정보처리방침](/privacy/)을 확인해 주세요.

백업도 목적이 끝난 정보를 무기한 보관하는 예외로 취급하지 않습니다. 실제 삭제 범위와 처리업체·백업의 반영 상태를 확인하여 결과를 안내하고, 복원 때문에 삭제한 계정이 다시 나타나지 않도록 관리합니다.

### 처리 과정과 안내

1. 요청을 접수하고 대상 계정·요청 범위를 확인합니다.
2. 필요한 최소한의 본인·대리인 확인을 진행합니다.
3. 법률상 보존 예외를 구분한 뒤 계정과 관련 데이터 삭제를 실행합니다.
4. 완료 시점·삭제한 범위·남은 법률상 보존 항목과 기간을 요청 이메일로 안내합니다.

요청은 지체 없이 처리하며, 개인정보 정정·삭제 요청의 결과는 원칙적으로 요청일부터 **10일 이내**에 법령에 따른 방식으로 안내합니다. 법률상 제한 사유가 있다면 이유와 이의 제기 방법을 설명합니다. 본인 확인을 이유로 기한을 자동 연장하거나, 근거 없이 모든 요청에 30일 대기를 요구하지 않습니다.

계정 삭제에는 비용을 부과하지 않습니다. 구매 취소·환불이 필요한 경우 그 의사도 함께 알려 주세요. 삭제와 환불은 별도 절차이며, Google 등이 자체적인 법적 의무에 따라 보유하는 기록에는 해당 서비스의 권리 행사 절차가 적용됩니다. 이 안내로 회사가 관리하거나 위탁한 데이터의 삭제 책임을 배제하지 않습니다.

## 게시·제출 차단 항목

- 앱 내 실제 요청 메뉴는 현재 검증되지 않았다. **권고 경로 `설정 → 계정 삭제 요청`**을 구현하고 로그인 중 계정을 안전하게 식별하여 같은 처리 절차로 연결한 뒤, 공개 본문에 정확한 경로를 넣는다. 이메일만 만들고 앱 경로를 생략할 수 없다.
- PlayFab·자체 서버·토큰·로컬 저장·문의 메일·백업별 실제 삭제 범위와 처리 시간을 시험해야 한다. 현재 숨겨진 탈퇴 버튼을 운영 중이라고 쓰지 않는다.
- ID 없는 외부 요청에 사용할 안전한 확인 수단을 서버팀과 확정한다. 계정에 연결된 이메일이 실제 검증·저장되지 않았다면 같은 발신 주소만으로 승인하지 않는다. 주문 영수증은 여러 단서 중 하나이며 이것만으로 모든 계정 삭제를 승인하지 않는다.
- 보호자·위임 요청에 필요한 자료를 정하고 불필요한 민감 식별자는 마스킹하도록 한다.
- 공개 본문은 삭제 기능 검증 후 실질적인 삭제 대상·백업 반영 최대 시간을 구체화한다. '10일 안내' 문구는 데이터가 무조건 10일 동안 남아도 된다는 허용이 아니다.
