# Google Play 데이터 보안 답변 작업표

2026-09-24. **내부 작성 자료이며 제출 답변 확정본이 아니다.** 광고 업체와 출시 서버 처리가 아직 확정되지 않아 모든 체크박스를 정직하게 확정할 수는 없다. 현재 소스, 출시 계획, 실제 서버 설정을 구별한다.

## 1. 설문 시작 부분

| 질문 | 현재 답변 방향 | 확정 조건 |
|---|---|---|
| 사용자 데이터를 수집 또는 공유하는가? | **예 방향** | Google·PlayFab 인증 경로가 있다. '게임 저장은 로컬'이라는 이유로 전체 수집 없음을 선택하지 않음 |
| 모든 수집 데이터가 전송 중 암호화되는가? | **확인 전 제출 보류** | 앱·광고·로그·고객지원 관련 모든 해당 전송 경로와 최종 SDK 설정 점검 |
| 계정 생성 방법 | **OAuth 기반 외부 로그인 방향** | Google 로그인 요청과 PlayFab `CreateAccount=true` 확인. 출시본의 게스트·다른 로그인 방식까지 함께 반영 |
| 계정·데이터 삭제 요청 URL | **현재 실제 공개 URL 없음** | [삭제 안내 초안](ACCOUNT_DELETION_KO.md)을 실제 처리 절차와 연결하고 게시 |
| 계정 삭제 없이 일부 데이터 삭제 요청 지원 | **운영 범위 미확정** | 실제 지원 항목이 정해졌을 때만 해당 선택. 문의 이메일의 존재만으로 지원 완료가 되지 않음 |
| 독립 보안 검토·인증 관련 질문 | **확인된 인증 없음** | 별도 검증을 받지 않았다면 인증을 받았다고 답하지 않음 |

계정 생성 기능이 있는 앱은 앱 내부와 외부에서 삭제를 요청할 수 있어야 한다. 현재 설정 메뉴의 탈퇴 버튼은 숨겨져 있고 유효한 삭제 경로가 확인되지 않았다. 이 상태를 문서만으로 '삭제 지원'이라고 제출할 수 없다. [계정 삭제 정책](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko)

## 2. 데이터 유형별 작성표

`확인`은 코드 또는 문서상 근거가 있다는 뜻이며 서버의 최종 보관 상태까지 시험했다는 뜻은 아니다. 아래 공유·선택 여부는 계약과 실제 동작으로 결정한다.

| Play 분류 후보 | 현재 근거 | 출시본에서 확정할 내용 | 목적 후보 |
|---|---|---|---|
| 개인정보 → 사용자 ID | PlayFab 계정·Google 인증 연동 확인 | 전송하는 Google/PlayFab/게스트 식별자, 수신 업체·보유기간 | 계정 관리, 앱 기능, 보안 |
| 개인정보 → 이메일 주소 | Google 로그인 설정 `RequestEmail=true` | 실제 앱 수신·서버 전송·저장 여부, 수집 필요성, 모든 이용자에게 선택 가능한지 | 계정 관리. 실제 사용하는 목적만 선택 |
| 개인정보 → 이름 | `RequestProfile=true`, PlayFab DisplayName 사용 | Google 이름과 게임 닉네임을 구분. 실제 전송·공개 여부 확인 | 앱 기능, 계정 관리 |
| 개인정보 → 기타 정보 | 연령·보호자 절차는 미검증 | 연령 구간/생년월일·동의 기록을 도입하면 분류·보관·제공처 추가 | 연령에 맞는 서비스, 동의 확인 |
| 앱 활동 → 앱 상호작용·기타 활동 | 진행도·재화·장비·스킬·퀘스트 로컬 저장 확인. 기존 서버 정보 조회 경로도 있음 | 어떤 활동을 서버·SDK로 보내는지 실제 최종 경로별 확정 | 앱 기능. 분석은 실제 분석 용도일 때만 |
| 금융 정보 → 구매 내역 | Google Play IAP 도입 계획 | 주문·상품·구매 토큰·지급 및 환불 상태의 처리 범위 | 상품 지급, 구매 검증, 보안 |
| 금융 정보 → 사용자 결제 정보 | 회사가 카드·계좌 원정보를 받는 근거는 확인 못함 | Google이 자체 처리하는 정보와 회사/SDK가 접근하는 정보 구분 | 실제 수집하는 경우만 |
| 기기 또는 기타 ID | 광고 SDK 미정. 인증·운영 SDK도 점검 필요 | 광고 ID, 앱 설치 식별자 등 실제 전송 항목. 사용자 ID와 구분 | 실제 광고·보안·분석 목적 |
| 위치 → 대략적 위치 | 현재 게임 기능의 위치 요구 근거 없음 | SDK가 IP로 지역을 추론·사용하는지 확인. 위치 권한이 없어도 해당될 수 있음 | 해당 SDK의 실제 목적 |
| 앱 정보 및 성능 → 비정상 종료·진단·기타 성능 | 원격 오류 수집의 최종 설정 미확인 | PlayFab·Unity·광고·별도 크래시 SDK의 자동 수집 설정 | 진단·분석·보안 중 실제 목적 |
| 메시지/사진 등 사용자 제공 자료 | 문의 메일로 접수할 수 있는 운영 계획 | 앱 내부 전송인지 외부 이메일인지, 첨부 자료 처리와 설문 적용 범위 구분 | 고객지원 |

연락처·SMS·마이크·카메라·정밀 위치·건강 정보는 조사 범위에서 실제 수집 기능을 확인하지 못했다. 최종 Android 매니페스트와 SDK까지 대조한 후 제외한다. 소스에서 단어가 없다는 이유만으로 확정하지 않는다.

## 3. 항목마다 결정할 여섯 가지

1. **수집:** 앱이나 SDK가 기기 밖으로 보내는지 확인한다. 기기에만 저장하는 항목과 구분한다.
2. **공유:** 다른 업체에 전달된다는 사실과 Play의 '공유' 분류는 같지 않을 수 있다. 회사 지시에 따르는 서비스 제공업체 예외 등의 조건을 계약과 실제 사용으로 판단한다. PlayFab 또는 Google이라는 이름만으로 전부 '공유 없음'을 선택하지 않는다.
3. **일시 처리:** 메모리에서 요청 처리 동안만 사용하고 그 뒤 보관하지 않는지 확인한다. 서버 로그·백업이 남으면 단순히 일시 처리라고 보지 않는다.
4. **필수/선택:** 모든 이용자가 해당 수집을 거부하면서 앱을 사용할 수 있는지 확인한다. 작동하지 않는 게스트나 공용 개발 계정은 선택권의 근거가 될 수 없다.
5. **목적:** 기능 제공, 계정 관리, 분석, 광고 등 실제 사용 목적만 고른다. 수집한 정보에 하나 이상의 목적이 있으면 모두 반영한다.
6. **출시 범위:** 특정 사용자·지역·빌드에서만 수집하는 데이터도 설문 적용 범위에 포함되는지 확인하고, 게시된 버전 전체와 답변을 맞춘다.

분류와 예외의 기준: [Google Play 데이터 보안 작성 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko).

## 4. 광고 업체 결정 시 받아야 할 정보

- 정확한 SDK 이름·버전, 미디에이션을 쓰면 모든 어댑터·광고 파트너 목록.
- 연령 확인 전 초기화·전송 여부, 아동/연령 미확인 설정, 광고 ID·기타 식별자 처리.
- 수집/공유 항목과 목적, 보유기간, 국외 이전, 삭제 요청 처리 방식.
- 아동 대상에 적합한 자체 인증 SDK 및 **해당 버전** 여부, 비맞춤 광고와 광고 소재·표현 통제.
- 실제 네트워크 요청을 대조한 결과. '비맞춤 광고'는 모든 데이터 수집이 없다는 뜻이 아니다.

현재 광고사는 미정이며 **AdMob을 선택했다고 문서에 기재하지 않는다.** 아동·연령 미확인 이용자는 Families의 식별자 및 광고 제한을 고려하여 처리한다. 앱 진입 시점에 광고·인증 SDK가 먼저 수집하는 경로까지 확인한다. [Families 정책](https://support.google.com/googleplay/android-developer/answer/9893335?hl=en)

| 최종 서버 동기화 항목, 서버 로그·크래시·분석 자동 수집 | 미확정 |

비밀번호·토큰·비밀키는 답변란에 넣지 않는다. 콘솔 설정이나 실제 계약을 확인하지 않고 국가·기간을 추정하지 않는다.

## 6. 조사 근거

- [Authentication.cs](../../Assets/_Project/Scripts/Server/Auth/Authentication.cs): Google 이메일·프로필 요청, PlayFab 계정 생성 요청·프로필 사용.
- [TitleScreenController.cs](../../Assets/UGUI/Scripts/Views/TitleScreenController.cs): Google/개발용 게스트 진입과 인증 세션 확인.
- [SettingsModalController.cs](../../Assets/UGUI/Scripts/Views/SettingsModalController.cs): 탈퇴 버튼 비활성화, 현재 기기 저장 안내.
- [LocalProgression.cs](../../Assets/_Project/Scripts/Core/Balance/LocalProgression.cs): 계정별 로컬 JSON 저장. 파일명 해시만으로 익명정보라고 간주하지 않음.
- [서버 연동 참고](../ServerDataAudit/overview.md): 내부 게임 함수와 실제 서버 API를 구별. 전체 진행 데이터의 원격 저장이 완성됐다는 증거로 쓰지 않음.
- [Packages/manifest.json](../../Packages/manifest.json): 선언된 Unity 패키지. 기본 모듈 존재만으로 실제 원격 분석 수집을 확정하지 않음.

현재 인증·삭제 문제는 출시 전 확인 대상으로 문서화했다. 다른 팀원의 서버 설정이나 구현을 변경하지 않았다.
