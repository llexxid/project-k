# 확률 공개 작성표와 게시 설계

2026-09-25. **내부 작성 자료. 출시 상품·확률표 확정 전 공개하지 않는다.**
현재 장비·마탑 뽑기 구현은 있지만, 유료 재화·패키지와 연결되는 최초 출시 상품은 미확정이다. 아래 표는 표시 형식이며 확정 수치를 임의로 채우지 않았다.

## 1. 유상 연결부터 판정

| 확인 항목 | 확인 결과 |
|---|---|
| 현금으로 직접 뽑기·이용권을 구매하는가 | 미확정 |
| 구매 재화로 뽑기 재화·티켓을 얻을 수 있는가 | 미확정 |
| 패키지·패스·보너스 지급을 거쳐 뽑기에 쓰이는가 | 미확정 |
| 유료·무료 재화가 동일 잔액에 합쳐지는가 | 미확정 |
| 무료 아이템과 유료 아이템을 결합하는 무작위 결과가 있는가 | 미확정 |
| 한정 기간·수량, 천장·등급 보정·결과 제외 조건이 있는가 | 최종 카탈로그·코드 확인 |

국내 소규모 예외와 Play 공개 요구는 [법무 검토](LEGAL_REVIEW_KO.md)에서 구분했다. 광고 보상만으로 얻는 경우도 유상성·상품 연결을 개별 확인하되 이용자에게 실제 확률을 안내하는 운영안을 권고한다.

동적 확률이 있으면 상태별 표 또는 계산 방법을 공개하고 현재 상태에 적용되는 확률을 구매 전에 확인할 수 있게 한다. 천장에는 발동 횟수·누적 범위·리셋 조건·보장 결과·보장 상태 확률을 적는다. 한정 상품은 기간·수량과 종료 조건을 적는다.

## 3. 현재 구현에서 특별히 대조할 사항

- 장비: 비활성 궁수용 활이 결과·미리보기에서 제외되는지, 등급 합계와 실제 개별 장비 확률이 일치하는지 확인한다.
- 마탑: 현재 모듈 문서는 희귀도 없이 스킬을 동일 확률로 제공한다고 설명한다. 전체 뽑기에서 스킬과 다른 보상 사이 확률, 스킬별 조건부 확률과 전체 확률을 구별한다.
- 중복은 새 스킬과 파편 지급을 구별한다. 결과 한 번의 확률과 10회 중 한 번 이상 획득할 확률을 혼용하지 않는다.
- 천장·확률 보정·제외 항목이 있으면 일반 확률 표 한 장으로 끝내지 않는다. 표시 자릿수·반올림과 합계 오차도 설명한다.
- 삭제된 ID나 오래된 기획표의 수치를 게시하지 않는다. 최종 실행 데이터의 안정적인 ID와 대조한다.

구현 참고: [현재 마탑 모듈](../../Assets/MageTower/README.md), [장비·환생 수정 검증](../QA/BALANCE_FIX_20260922.md).

## 4. 배포 확인

1. 기획 담당자가 최종 상품·유상 연결·카탈로그 버전을 지정한다.
2. 개발 담당자가 실제 추첨 코드의 분기별 확률을 계산한다. 시뮬레이션 관측 빈도만으로 확정 확률을 대신하지 않는다.
3. 같은 원본으로 게임 내 표와 웹 표를 생성하거나 서로 대조한다.
4. 운영 담당자가 발효 시각·과거 버전·변경 공지를 확인한다.
5. 구매 직전부터 앱과 웹의 안내에 접근할 수 있는지 확인한다. 홈페이지에만 올려 두고 앱에서 찾을 수 없게 만들지 않는다.

현재 공개 URL, 확정 확률, 유료 상품, 광고물의 적용 문구는 미확정이다. [국내 표시 기준](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=161218493&gubun=), [Play 결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en).
