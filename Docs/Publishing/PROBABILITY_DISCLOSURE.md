# 왕국군 키우기 확률 공개 자료

검토일: **2026-09-27**. 소스 조회 당시 `PlayerSettings.bundleVersion` 0.15.0, 마탑 카탈로그 `mage-5`. 최종 배포 AAB와 시행 일시는 아직 확정되지 않았다. 기존 작성표의 빈칸을 실제 코드·카탈로그에서 계산한 자료로 대체했다.

**현재 확인:** 장비·마탑 뽑기는 고대주화로 동작한다. 신규 상점은 실제 결제·광고 없이 UI만 제공한다. 향후 고대주화·뽑기권 판매를 활성화하면 유료와 직접·간접 연결된 무작위 보상이 되므로 판매 전에 공개·신고를 갱신해야 한다. 현금화·이용자 거래 상품은 현재 요청 범위에 없다.

## 확률 안내 읽는 법

아래는 현재 개발 코드와 카탈로그를 기준으로 정리한 「왕국군 키우기」 장비·마탑 뽑기 정보입니다. 확률은 **1회 뽑기** 기준이며, 여러 번 시도했을 때 반드시 해당 결과가 나온다는 뜻은 아닙니다. 별도로 설명한 장비 에픽 보장 조건만 예외입니다.

두 뽑기 모두 고대주화 50개로 1회, 500개로 10회를 진행하는 구성이며, 현재 상점의 현금 구매·광고 보상 버튼은 기능 안내용입니다. 뽑기권 판매와 광고 보상 지급은 아직 제공하지 않습니다.

### 에픽 보장과 중복·자동 분해

- 에픽을 얻지 못한 장비 뽑기가 39회 누적되면 **다음 1회는 에픽 100%**입니다. 그때 엑스칼리버와 에어 지팡이의 확률은 각각 50%입니다.
- 일반 상태에서 에픽을 얻어도 누적은 0으로 초기화됩니다. 전직 파편 결과는 에픽 미획득 횟수에 포함됩니다.
- 10회 뽑기는 각 회차를 순서대로 처리합니다. 묶음 안에서 보장 조건에 도달하면 해당 회차에 적용하고, 이후 회차에는 초기화된 상태를 적용합니다. 10회를 묶었다는 이유의 별도 보장은 없습니다.
- 활은 현재 뽑기 결과에서 제외됩니다. 같은 장비를 여러 번 획득할 수 있습니다.
- 자동 분해 설정은 추첨 확률을 바꾸지 않습니다. 설정에 해당하는 장비를 얻으면 장비 대신 강화석을 지급하며, 새 일반·레어·에픽 장비의 기본 분해량은 각각 1·4·12개입니다. 에픽 자동 분해도 에픽 획득으로 처리되어 누적이 초기화됩니다.

스킬 획득 합계는 50%이며 스킬 8종은 동일 확률입니다. **전체 1회에서 각 스킬은 6.25%**, 스킬 획득이 정해진 조건 안에서는 각각 12.5%이므로 두 숫자를 혼동하지 마세요.

이미 가진 스킬이 나오면 **해당 스킬의 각성 파편 30개**를 받습니다. 보유 여부는 추첨 확률을 바꾸지 않습니다. 현재 별도 천장, 10회 추가 보장, 스킬 희귀도별 확률은 없습니다. 비활성 스킬은 추첨 목록에 들어가지 않습니다.
