# 왕국군 키우기 한국 출시 법무 검토와 문서 운영안

조사 기준일: **2026-09-25**. 대한민국 우선 출시, 광고·Google Play 인앱결제, 만 13세 이상 대상 선정안, Google·PlayFab 인증 코드가 있는 현재 프로젝트 기준이다.

이 문서는 공식 법령·지침·플랫폼 정책을 대조한 실무 검토다. 변호사의 법률의견서나 적법성 보증은 아니다. 특히 사업자 등록 상태, 유료 상품 구성, 광고사, 실제 서버·계약·삭제 처리는 아직 확인되지 않아 그 부분의 최종 판단은 남아 있다. 화면에 적은 문구와 실제 운영이 일치해야 한다.

## 1. 규모에 맞는 작성 방법과 전문가 활용

**권고: 공식 서식으로 내부 초안 작성 → 실제 데이터·상품·운영과 대조 → 출시 직전 범위를 정한 외부 검토 → 내부에서 변경 관리.** 전담 변호사 채용을 전제로 할 필요는 없다. 업계 전체의 채용·작성 방식 통계를 확인한 것은 아니며, 이 구성은 현재 팀의 비용과 위험을 고려한 실무 권고다.

|---|---|---|

공정위 게시물의 제목·개정일·첨부 존재는 공식 검색 결과로 확인했으나 원문 페이지 직접 조회는 403 응답이었다. 첨부 전문을 이번 조사에서 읽었다고 주장하지 않는다. 새 [이용약관 초안](TERMS_OF_SERVICE_KO.md)은 해당 문서를 그대로 전재한 것이 아니라 확인한 법령과 프로젝트 조건으로 작성한 검토용 초안이다. 최종 검토 때 공식 첨부 전문과 대조한다.

별도로 확인한 [공정위 공식 개정 설명](https://www.korea.kr/news/policyNewsView.do?newsId=156617123)은 서비스 종료 이후에도 **최소 30일 이상 유료아이템 환불 대응 창구를 운영**하는 내용을 표준약관에 추가했다고 안내한다. 표준약관의 권고·계약 조건과 법률상 의무를 구별하되, 우리 서비스 종료 계획에도 이 기준을 반영하는 안을 검토한다. '표준약관과 다르면 모두 불법'이라고 단정하지 않는다.

이번 게임에서는 다음 항목을 **게임·개인정보·전자상거래 경험이 있는 변호사에게 한 묶음으로 한 차례 검토**받는 것을 권고한다. 비용은 정해진 표준 수가가 없으므로 범위·수정 횟수를 명시한 견적을 받는다.

- 만 13세 이용자의 개인정보·로그인·법정대리인 확인 흐름.
- 유료 재화·확률형 상품·미성년자 결제·청약철회·서비스 종료 처리.
- PlayFab·Google·광고사·호스팅의 계약 역할과 국외 이전 근거.
- 사업자·게임제작/배급 등록, 플랫폼 판매 구조에 따른 통신판매 신고·표시.

의뢰 자료는 문서만 주지 말고 로그인부터 결제·삭제까지의 화면, SDK 및 수신업체 목록, 보유기간, 상품·확률표를 함께 준다. 개발자가 정해야 하는 서버 보유기간이나 실제 상품 동작을 변호사가 추정하도록 맡기지 않는다.

[개인정보 포털 기술지원](https://www.privacy.go.kr/front/per/tec/tecSupportReq.do)은 지원 대상과 범위를 확인해 활용할 수 있다. [KOCCA 법률·노무 상담창구 안내](https://welcon.kocca.kr/ko/info/business/1954003)도 상담 가능 여부를 확인할 경로다. 후자는 불공정행위 예방·피해 구제 중심 안내이므로 출시 문서 전체 무료 작성이 보장되는 것으로 해석하지 않는다. 세무·사업자 신고는 세무사 또는 관할 기관 확인도 병행한다.

개인정보 보호책임자는 변호사와 다른 역할이다. 소규모 사업자 관련 기준을 충족하는 경우 별도 지정 대신 사업주·대표자가 그 역할을 맡는 규정이 있으나, 개인정보 보호 책임이 사라지는 것은 아니다. [개인정보 보호법 제31조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033215381)

### 개인정보에서 놓치기 쉬운 부분

1. 계정 식별자가 가명·해시라는 이유만으로 개인정보가 아니라고 처리하지 않는다. 이메일·프로필 요청을 실제로 쓰지 않는다면 개발자가 수집 범위를 줄이는 편이 문서에 넓게 쓰는 것보다 낫다.
2. 위탁 업체와 제3자 제공을 역할에 따라 구별한다. 'Google 등' 대신 계약상 법인·업무·항목을 특정한다. 해외 서버뿐 아니라 해외에서 접근하는 경우도 국외 이전 검토 대상이다.
3. 국외 이전은 항상 별도 동의만 가능한 것도, 방침에 적기만 하면 가능한 것도 아니다. 계약 이행에 필요한 국외 처리위탁·보관 등의 해당 근거와 공개·통지 조건을 확인한다. 광고 프로파일링까지 같은 근거로 묶지 않는다. [개인정보 보호법 제28조의8](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331979)
4. 삭제 예외는 정보 유형·목적·기간별로 제한한다. 구매 기록을 보존해야 한다고 전체 계정·광고 식별자·게임 로그를 5년 보관하지 않는다.
5. 공개 문서 외에도 접근 권한, 위탁 계약·감독, 파기 작업, 문의 처리, 유출 대응 담당자·절차가 있어야 한다. 개인정보처리방침의 보안 문장은 실제 실행 중인 조치만 적는다. [안전성 확보 조치](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029332413)

2026 지침 PDF의 항목·법적 근거, 아동, 국외 이전, 책임자·권리 구제, 소상공인 예시를 확인했다. 시행 중 법령과 프로젝트 처리 현황을 우선한다.

### 결제·환불과 기록 보존

- 청약철회는 원칙적인 7일 규정과 디지털콘텐츠의 예외 요건을 함께 검토한다. '결제 즉시 무조건 환불 불가' 또는 'Google에만 문의'라는 약관으로 끝내지 않는다. 사용·제공 개시, 사전 고지 및 법정 조치, 미사용 부분, 표시와 다른 제공을 구분한다.
- 표시·광고나 계약과 다른 제공에는 공급 후 3개월과 그 사실을 안 날 또는 알 수 있었던 날부터 30일이라는 별도 기간이 적용된다. 두 기간 중 하나만 남아 있으면 언제나 가능한 것으로 안내하지 않는다.
- 청약철회·환불·미성년자 구매 취소·계정 삭제를 서로 다른 처리로 구분하고 구매 토큰·지급 내역·사용 내역을 대조한다. 정당한 취소 요청을 부정 이용으로 일괄 제재하지 않는다.

근거: [전자상거래법 제17조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022784073), [표시와 다른 제공의 기간 해석](https://law.go.kr/expcInfoP.do?expcSeq=314906).

[전자상거래법 시행령 제6조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1018638379). 회사가 보유·관리하는 해당 기록의 범위와 기산점·분리 보존을 확정한다. 모든 문의를 분쟁으로 보거나 모든 데이터를 이 기간에 맞춰 보관하지 않는다.

### 확률형 아이템: 작은 회사도 별도 확인 필요

게임법 시행령에는 업종·중소기업 요건 및 최근 3년 연평균 매출액 1억원 이하 등의 표시의무 제외 조건이 있다. **제작·배급·제공 주체 각각의 조건**, 신규 사업의 환산 기준을 확인해야 하므로 '우리 매출이 작다'만으로 면제라고 결론 내리지 않는다. 플랫폼과의 제공 구조도 필요한 경우 관할 기관에 확인한다. [시행령 제19조의2](https://law.go.kr/lsLinkCommonInfo.do?lspttninfSeq=56615)

이와 별개로 Play는 구매로 무작위 가상 아이템을 받는 방식에 대해 구매 전에 가까운 위치에서 확률을 공개하도록 요구한다. 우리 게임은 **면제 여부와 관계없이 실제 확률을 공개하는 운영안**을 권고한다. 무료·유료 재화가 섞이거나 패키지를 거쳐 뽑기에 사용되는지도 조사한다. [Google 결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738?hl=en)

홈페이지에는 등급별 합계만 올리지 말고 상품·개별 결과·변동 확률·천장 조건·기간·변경 적용 시점 등 해당 정보를 검색·확인할 수 있게 구성한다. 게임 내 구매 전 경로도 마련한다. 국내 표시의무가 적용된다면 게임·홈페이지·광고물 각각의 요구를 대조한다. [시행령 별표 3의2](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=161218493&gubun=)

[확률 공개 작성표](PROBABILITY_DISCLOSURE.md)에 현재 구현과 최종 상품을 대조하는 형식을 준비했다. 현재 수치를 출시 확정 확률처럼 게시하지 않는다.

### 사업 등록·권리·기타 운영

- 사업자등록, 통신판매업 신고, 게임제작업·게임배급업 등록은 서로 다른 제도다. 실제로 필요한 등록과 예외는 관할 기관에서 확인한다. Play 계정을 만들었다고 모두 처리되는 것은 아니다. [게임제작·배급 등록](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=1&cciNo=2&cnpClsNo=1&csmSeq=2858&popMenu=ov)
- 한국 개발자의 공개 연락처·유료/IAP 사업자 정보는 별도로 준비한다. 개인 휴대전화 대신 실제 문의를 받을 수 있는 업무용 번호를 권고한다. [Google 한국 개발자 안내](https://support.google.com/googleplay/android-developer/answer/3255733?hl=ko)
- 자체등급분류 적용과 한국 유통 등급을 확인한다. 등급 문항에는 유료 무작위 획득, 폭력 표현, 이용자 교류 등을 실제 출시본 기준으로 신고한다. [Play 콘텐츠 등급](https://support.google.com/googleplay/android-developer/answer/9859655?hl=ko)
- 팀원·외주 계약에서 소스·그림·음원 등의 권리 귀속과 상업 이용·수정 권한을 명확히 한다. 마켓 에셋은 구매 기록·라이선스·좌석 및 법인 범위·재배포 제한을 점검한다. 원본 에셋을 웹 다운로드로 배포하지 않는다. [Unity Asset Store EULA](https://unity.com/legal/as-terms)
- 폰트 임베딩, 음악·효과음, 오픈소스 고지, AI 도구의 생성물 이용 조건도 실제 사용 품목별로 기록한다. 상표·게임명 선행 조사와 홍보물의 권리 검토를 추가한다. 이번 작업은 개별 자산의 권리 전수 감사가 아니다.
- 허위 할인·보상 보장·실제 없는 게임 장면, 협찬 표시 누락, 광고성 푸시·메일 발송은 별도 검토한다. 처음에는 홍보 메시지 수신 동의를 게임 이용 동의에 묶지 않는 운영안을 권고한다.
- 정기결제·배틀패스·현금화·이용자 거래·채팅·해외 출시를 추가하면 지금 범위를 넘어서는 추가 검토가 필요하다. 현재 포함된 것으로 가정하지 않는다.

## 3. 문서와 실제 기능을 함께 관리하기

| 관리 대상 | 책임 역할 | 갱신 시점·증거 |
|---|---|---|
| 데이터 목록·SDK·처리업체 | 서버·클라이언트 담당 | 로그인·서버·SDK 변경 전. 데이터 종류/목적/수신자/국가/기간/삭제 방법 |
| 개인정보처리방침·동의 화면 | 운영·개인정보 담당 | 데이터 변경 전. 게시본·시행일·필요한 재동의 기록 |
| 이용약관·상품/환불 안내 | 사업·운영 담당 | 상품·제재·서비스 운영 조건 변경 전. 변경 전후·고지/동의 근거 |
| 확률표 | 기획·개발 담당 | 확률·천장·풀·유료 연결 변경 전. 런타임 원본과 공개값의 대조 |
| 삭제·권리 요청 | 운영·서버 담당 | 요청마다 접수·본인 확인·실행·예외·완료 기록. 접근 제한된 저장소 사용 |
| 공개 사이트·콘솔 URL | 등록 담당 | 배포 때 링크 검사. 도메인 갱신·관리자 계정 복구 수단 유지 |

추천 운영 주기는 **업데이트마다 변경 영향 확인 + 분기별 전체 대조 + 사고/업체 변경 즉시 검토**다. 이는 내부 관리 권고이며 일률적인 법정 점검 주기라고 표시하지 않는다. 파일 이름을 바꾸며 복제본을 늘리기보다 현재 운영 문서를 수정하고 Git 기록·실제 공개본을 보존한다.

공개 페이지의 경로는 고정하고 시행일과 과거 버전 링크를 표시한다. 개인정보처리방침에 일괄 '7일/30일 전 고지하면 모든 변경에 동의한 것'이라고 쓰지 않는다. 변경 내용에 따라 별도 동의·통지 필요성을 판단한다.

## 4. 공개 전 완료 기준

- [ ] 광고 SDK와 파트너·아동 설정 확정.
- [ ] 실제 데이터·보유기간·국외 이전·삭제·보호자 절차를 담당자가 확인.
- [ ] 운영 사업자와 등록·신고·업무 연락처 확정.
- [ ] 이용약관·유료 상품·환불·확률 공개를 실제 UI와 대조.
- [ ] 외부 전문 검토의 의견과 조치 결과 기록(팀 권고).
- [ ] 문서의 미확정 표시 제거, 앱과 공개 URL 연결, 읽기·삭제 요청 시험.
- [ ] 최종 AAB의 SDK·권한·데이터 흐름과 Play 신고가 동일함을 확인.

콘솔·서버·DNS·광고 계정을 변경하거나 문서를 외부 공개하지 않았다. 개인 전화번호와 비밀번호는 산출물에 넣지 않았다.
