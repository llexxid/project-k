# 공개 웹페이지와 연락처 준비안

2026-09-24. 루도스(Ludos) / 왕국군 키우기 / 대한민국 우선 출시.

## 권고안

**기존 이메일 도메인 `ludosinteractive.com`에 소규모 정적 사이트를 운영한다.** 처음에는 게임 소개·문의, 개인정보처리방침, 계정 삭제 안내의 세 페이지면 충분하다. 약관·상품 운영 정책·확률 공개는 실제 상품과 운영 방침 확정에 맞춰 추가한다.

이메일 주소가 있다고 도메인 관리 권한·DNS 접속·웹 호스팅까지 확인된 것은 아니다. 현재 도메인 소유권, DNS, 사이트 호스팅은 확인·변경하지 않았다. 게임 서버 담당자의 운영 서버에 새 서비스를 설치할 필요가 없는 구성을 권고한다.

| 방법 | 당장 필요한 작업 | 이후 관리 | 판단 |
|---|---|---|---|
| 외부 서비스의 공개 HTML 문서 페이지 | 계정·공개 접근·고정 URL 설정, 본문 확정 | URL·공개 권한 유지, 기능 제약 확인 | 임시 방법 가능. 로그인·지역 제한 없이 읽히고 방문자 편집이 불가능해야 함 |
| 기존 도메인 + 관리형 정적 호스팅 | 사이트 파일·호스팅 설정·최소 DNS 연결 | 동일 주소에서 문서만 갱신 | **권고.** 여러 필수 페이지와 향후 광고 관련 파일을 한곳에서 관리 |
| 게임 서버에 별도 웹앱 구축 | 서버·배포·인증·보안·운영 추가 | 서버 담당자의 관리 범위 증가 | 현재 간단한 공개 문서 제공 목적에는 과도함 |

회사 홍보용 대형 홈페이지는 필요하지 않지만, 개인정보처리방침과 삭제 요청에는 실제 공개 웹 경로가 필요하다. 이메일만 콘솔의 URL 칸에 넣거나 PDF 파일만 올리는 것은 이 구성을 대신하지 못한다. [사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311?hl=ko), [삭제 요청 웹 리소스](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko)

## 페이지 구성

아래는 **제안 경로**이며 현재 존재하거나 작동하는 주소가 아니다. 실제 게시 완료 후에만 콘솔에 URL을 입력한다.

| 제안 경로 | 내용 | 원본 자료 |
|---|---|---|
| `/kingdomidle/` | 게임 이름·간단 소개·운영사·문의·정책 링크 | [스토어 소개문](STORE_LISTING_KO.md) |
| `/kingdomidle/privacy/` | 확정한 개인정보처리방침·시행일 | [개인정보 초안](PRIVACY_POLICY_KO.md) |
| `/kingdomidle/delete-account/` | 외부 계정 삭제 요청 방법·범위·기간 | [삭제 안내 초안](ACCOUNT_DELETION_KO.md) |
| `/kingdomidle/terms/` | 서비스·계정·유료 상품·미성년자 구매·환불 등 실제 약관 | 상품·운영 방침 확정 후 작성 |
| `/kingdomidle/probabilities/` | 적용 대상 확률형 상품의 확률·조건·변경일 | 최종 상품과 런타임 확률 데이터 대조 후 작성 |
| `/app-ads.txt` | 선정 광고사가 요구하는 판매자 정보 | 광고사 확정 후 제공된 실제 값 사용 |

광고사는 아직 미정이다. AdMob을 선택하는 경우 앱 확인에 필요한 `app-ads.txt` 요건을 검토한다. 이 파일이 모든 광고사·모든 앱에 동일하게 필요한 것으로 단정하지 않는다. [AdMob 앱 확인 안내](https://support.google.com/admob/answer/14538460?hl=en)

## 전화번호와 계정 표시

- 개인 전화번호는 저장소나 공개 초안에 기재하지 않았다.
- 앱별 지원 전화번호가 선택 입력인 경우에는 생략한다. 그러나 한국 개발자 계정의 공개 문의 연락처는 별도 요건이며 개인 계정도 전화번호를 요구한다.
- 실제 연락·인증이 가능한 업무용 번호를 준비하는 것이 권고안이다. 가짜 번호나 수신하지 않는 번호로 채우지 않는다.
- 사용자가 알려준 사업자명은 루도스(Ludos)다. 콘솔 표시명 `Ludos Interactive`, 현재 `Personal account` 유형, 법적 사업자·결제 프로필의 관계는 계정 소유자가 확인해야 한다. 이번 작업에서는 전환·수정하지 않았다.

[한국 개발자 추가 연락처 안내](https://support.google.com/googleplay/android-developer/answer/3255733?hl=ko)

## 게시 담당자에게 넘길 작업

1. 도메인 관리 권한과 기존 이메일 DNS를 확인하고, 이메일 수신에 필요한 레코드를 보존하는 방식으로 웹 호스팅을 연결한다.
2. 게임 서버와 독립된 정적 호스팅을 선택하고 HTTPS·고정 경로를 설정한다. 비용과 계정 소유권은 선택한 제공자의 실제 조건을 확인한다.
3. 개인정보·삭제 문서의 미확정 값을 실제 운영에 맞춰 확정한다. 초안 경고나 자리표시자를 공개하지 않는다.
4. 가능하면 광고·외부 분석 스크립트 없이 페이지를 구성한다. 호스팅 제공자의 접속 로그도 개인정보 검토 범위에 넣는다.
5. 로그인하지 않은 브라우저·모바일에서 본문·링크·메일 주소를 확인한다. 접근 지역을 한국으로 제한하지 않는다.
6. 앱 내부와 Play Console에서 동일한 확정 URL을 사용한다. 담당자가 실제 입력·저장한다.
7. 정책 변경일·이전 문서·수정 근거를 보관한다.

현재 완료한 범위는 페이지 구성과 문구 준비다. 사이트 생성·게시, 호스팅 계약, DNS 및 게임 서버 변경은 수행하지 않았다.
