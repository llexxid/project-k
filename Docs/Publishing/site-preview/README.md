# 왕국군 키우기 안내센터 시안

외부에 게시하지 않은 로컬 검토용 정적 사이트다. `dist/index.html`을 브라우저에서 열면 서버 없이도 탐색할 수 있다. 정책 전문과 사실 확인의 기준은 상위 폴더의 Markdown 문서다.

- 개인정보·약관 화면은 문서의 읽는 구조와 주요 주제를 보여 주는 요약이며 법적 확정본이 아니다.
- 계정 삭제 기능, 메일 전송 폼, 확률 수치를 구현하거나 작동하는 것으로 표시하지 않는다.
- 외부 글꼴·분석·광고 SDK·쿠키·방문자 데이터 저장을 추가하지 않았다.
- 아이콘은 기존 프로젝트의 `Assets/_Project/Art/Sprites/play_store_512.png`를 변경 없이 복사했다.
- 문서 원본이나 프로젝트 전체를 공개하지 않고, 공개 준비가 끝난 파일만 배포한다. 시안의 `noindex`는 접근 통제가 아니다.
- 운영 공개 전 실제 전문·시행일·사업자 표시·이전 버전과 독립된 `/privacy/`, `/terms/`, `/delete-account/`, `/probabilities/`, `/support/` 경로로 전환한다. 현재 해시 이동 주소를 콘솔에 입력하지 않는다.

비용·호스팅·URL 설계: [WEBSITE_PLAN.md](../WEBSITE_PLAN.md). 프로젝트 작업 지침: [AGENTS.md](../../../AGENTS.md).

- 좁은 화면의 이메일 가독성을 위해 항목명과 값을 세로로 배치한 뒤 가로 넘침을 재확인했다.
- 문서 상대 링크, 시안 링크·자산, 중복 ID, 인라인 JavaScript 구문 확인. 개인 휴대전화 패턴 0건. 아이콘은 원본과 해시 일치.
